## Cultural & Visual DNA — Derivation
- Searched/fetched official overview → found “以前沿信号为引领” and project-based frontier topics → chose dynamic grid / signal wave motif.
- Fetched official research list → found repeated open-source and AI infrastructure language (MOSS, SGLang, GitHub, HuggingFace) → chose code labels, modular cards, versioned research templates.
- Fetched The Paper → found Xuhui Beiyang AI town, new buildings and glass curtain wall → chose glass mist, deep navy/blue-gray spatial palette, luminous signage style.
- Fetched CCTV → found “青年师生、链接全球资源”, young mentors, five research阵地 → chose young co-founder tone and modular sub-brand architecture.
- Fetched MIT Media Lab case → found grid-to-many-glyph system → translated into possible SII/创智 grid mark with research阵地 derivatives.
