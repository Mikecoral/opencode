# Brand Tokens: 创智学院

## Color Palette
| Role | Name | Hex | Usage |
|------|------|-----|-------|
| Primary | Deep Lab Navy | #0A102A | Logo fields, dark research backgrounds, high-contrast identity applications |
| Accent | SII Signal Blue | #0F62FE | The single active signal color for logo accents, links, CTAs, nodes, scanning lines |
| Surface | Glass Mist | #F6F8FB | Light backgrounds, website cards, research release surfaces, negative space |
| Muted | Grid Gray | #A2A9B0 | Grid lines, metadata, secondary labels, technical annotations |
| Text | Graphite | #161616 | Body text, black-on-light lockups, formal institutional copy |

**Accent discipline:** one accent color only. Compute Cyan and Creation Orange from the brief are not used in this first exploration round to keep the logo set coherent and avoid multi-accent “AI neon” slop.

## Typography
| Role | Style Description | Weight Range |
|------|-------------------|-------------|
| Display / Logo | Rational narrow humanist Chinese sans-serif paired with geometric Latin sans-serif; open counters, precise but not cold | Semibold / Bold |
| Body | Humanist sans-serif for long academic and institutional content; readable, neutral, modern | Regular / Medium |
| Caption | Semi-monospace or mono-influenced style for project numbers, versions, labels, GitHub/open-source metadata | Regular / Medium |
