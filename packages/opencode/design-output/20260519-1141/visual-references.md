# 视觉参考资料

## 使用的简报输入
本次视觉研究主要受以下简报章节影响：第2章“新型 AI 研究型学院 + 创客社区 + 产业转化枢纽”的复合定位；第4章“前沿、敢闯、年轻、实战、开源、共同体式”的品牌个性；第5章关于“模型、网络、推理路径、迭代版本”“可组合模块、节点连接、可变网格”“滨江、玻璃幕墙、实验楼、夜间灯光、讨论室”“草图、代码、实验照片、demo 截图与系统架构图”的视觉DNA；第8-10章色彩、字体、符号策略；第11章官网、招生营、科研发布、TechFest、合作提案与空间导视的优先级。评审中特别提醒“蓝绿科技色需要严格避免泛化 AI 视觉”，因此本次研究将蓝绿网格只作为一个方向，而另设浅色创客社区与强编辑排版方向。

## 参考案例
| 案例 | 来源URL | 关联性 | 可借鉴的视觉手法 | 需要规避的做法 |
|------|---------|--------|----------------|--------------|
| MIT Media Lab 视觉识别 / Pentagram | [https://www.pentagram.com/work/mit-media-lab](https://www.pentagram.com/work/mit-media-lab) | 同属研究型、跨学科、项目组众多的科技教育机构。页面明确说明以 7×7 网格生成 ML 标志，并把同一底层网格扩展到 23 个研究组。 | 用“一个底层规则”而非单一装饰图案管理多研究方向：固定主标 + 可派生研究组 glyph；黑白/中性底色让彩色符号成为研究差异；Helvetica 式中性无衬线让系统不抢科研内容。具体性在于每个研究组都有可识别的网格字形，而不是抽象连接线。 | 不要直接套用 7×7 彩色方块或 MIT 式 Helvetica 崇拜；创智学院若只做节点矩阵，会落入“实验室=网格”的惯性。应把网格转译为“创 / 智 / SII / 项目制导师组”的中文与组织逻辑。 |
| MIT Media Lab 官网运行态 | [https://www.media.mit.edu/](https://www.media.mit.edu/) | 可观察研究机构如何在真实官网中承载新闻、研究组、标签、人物与外部媒体引用，接近创智学院官网/科研进展需求。 | 以大字号短句开场；列表中把研究组 glyph、类别、标题、来源、日期、研究组和标签并置，形成“研究数据库”而非宣传册；大量留白和黑色文字让多学科内容保持统一。具体性在于每条内容带研究组图标和标签，用户能横向探索项目生态。 | 不要把官网做成单张炫酷 hero 图；也不要让科研发布只有海报感，缺少可检索的项目标签、组别、日期、开源链接与论文/代码入口。 |
| The New School 视觉识别 / Pentagram | [https://www.pentagram.com/work/the-new-school/story](https://www.pentagram.com/work/the-new-school/story) | 同为教育机构，但重点不是科技网格，而是用定制字体和品牌架构表达“多学院、多项目、持续演化”。 | 定制 Neue 字体把正常、宽、超宽字形混排；平行横线作为组织装置；黑色主标 + 红色学院/项目名称建立母品牌与子项目层级。可借鉴“标题字宽变化 = 组织持续变形”的方法，用于招生营、TechFest、开源项目名称。 | 不要把创智做成艺术学院式纯排版海报；过度拉伸中文可能降低可读性。可变字宽应只用于英文 SII、项目编号、活动标题或短中文标题，不应影响长篇招生说明。 |
| IBM Carbon Design System：色彩与主题 | [https://carbondesignsystem.com/elements/color/overview/](https://carbondesignsystem.com/elements/color/overview/) | 创智学院需要大量官网、科研进展、项目卡片、合作提案与数据图表；Carbon 提供数据密集 UI 的颜色角色、浅深主题和层级模型参考。 | 灰阶占主导、核心蓝承担主操作、辅助色克制使用；浅色主题用 White / Gray 10 交替分层，深色主题逐层变亮；色彩以 token 角色管理背景、图层、边框、文本、链接、状态。具体性在于“颜色按角色和层级工作”，不是按喜好堆霓虹色。 | 不要把 Carbon 直接变成 IBM 风；也不要用大量中间灰导致画面发脏。若采用深色界面，必须制定层级规则和对比度规则，避免蓝绿线条满屏。 |
| IBM Carbon Design System：字体 | [https://carbondesignsystem.com/elements/typography/overview/](https://carbondesignsystem.com/elements/typography/overview/) | 简报要求中英文长文、科研标题、代码/论文名、项目标签共存；Carbon 的 productive / expressive 两套字阶适合转译为“科研阅读”和“活动传播”双模式。 | 使用 Sans / Serif / Mono 家族分工；productive 字阶用于产品/数据密集界面，expressive 字阶用于营销和长文扫描；正文保持中性色，蓝色用于主操作。具体性在于不同触点有不同字阶，而不是全场景一个大标题模板。 | 不要把 Mono 字体滥用于所有内容；代码感应作为标签、版本号、论文编号和开源链接的局部语气，正文仍需理性人文无衬线保证中文可读。 |
| 上海创智学院现有官网与“视觉创智”栏目 | [https://www.sii.edu.cn/main.htm](https://www.sii.edu.cn/main.htm)、[https://www.sii.edu.cn/sjcz/list.htm](https://www.sii.edu.cn/sjcz/list.htm) | 这是未来品牌更新必须兼容的真实触点：官网已有 Logo、主导航、科研进展、创智日历、招聘入口与影像栏目。 | 现有内容已经包含科研图、活动照片、成果发布会、AI 概念片、训练营、合影等素材类型；可借鉴“科研进展 + 日历 + 招聘号召”的内容结构，重做封面图、标题层级、日期模块与标签系统。 | 不要脱离官网内容生态重新发明一套只能用于品牌手册的视觉；同时要避免现有栏目中照片/PNG/JPEG 风格不一的问题，应建立封面生成规则和影像裁切规范。 |
