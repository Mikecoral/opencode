# 资产生成计划

## 决策依据
本次以用户认可的“RUNNING-GRID 可运行网格”为起点，将其归入 `research-signal`：简报反复强调“AI 前沿阵地、项目制导师组、开源引擎、可变网格、真实系统”，且第10章明确建议以 7×7 或 9×9 网格生成 SII、创/智抽象笔画与子符号。交付上不从“学校”默认物料出发，而优先解决第11章中证据最强的官网、科研进展、开源成果与招生入口的数字传播一致性。

## 视觉方向
- 所选方向：`research-signal`（具体执行路线：RUNNING-GRID 可运行网格）
- 原因：`direction-options.md` 推荐优先探索 RUNNING-GRID；它最能把简报中的“模型、网络、推理路径、迭代版本”“可组合模块、节点连接、可变网格”和“开源成果发布”转译为一套可扩展视觉语言。
- 规避了什么：规避“学校=盾徽/书本/招生海报/校园大图”的传统高校默认方向，也规避无意义神经网络背景、霓虹粒子海、3D 芯片隧道等泛 AI 视觉。

## 交付策略
- 所选策略：`digital-system`
- 原因：第11章首要触点中，官网首页与科研进展模板、科研项目与开源成果发布模板、招生营/博士遴选数字入口都依赖统一的数字模板、标签层级、项目 metadata 与开源链接呈现；这比首轮做完整活动系统、空间系统或周边更贴合当前证据。

## 触点优先级
| 触点 | 优先级 | 简报依据 | 决策 |
|------|--------|---------|------|
| 官网首页与科研进展模板 | 首要 | 官网是官方首要入口，科研进展更新频繁，需统一封面图、标题层级、项目标签和开源链接。 | 包含 |
| 科研项目与开源成果发布模板 | 首要 | 科研进展集中呈现 MOSS-VL、LWD、MOSS-TTS-Nano、智能体等成果，需要项目海报、论文摘要图和社媒卡片规范。 | 包含 |
| 招生营 / 博士遴选视觉系统 | 首要 | 招生页发布夏令营博士生遴选、考试大纲、机考手册等内容，需要高潜学生快速识别入口与流程。 | 包含为数字入口模板，不扩展成传统招生套装 |
| 创智未来大会 / TechFest 活动系统 | 首要 | TechFest 与开放日是展示人才培养、科研和生态的重要窗口。 | 推迟：属于 `campaign-system`，本轮仅让数字模板具备未来活动承载能力 |
| 合作生态与产业伙伴提案模板 | 可选 | 学院与企业、资本、孵化机构协作密切，未来需要合作简报与成果转化模板。 | 推迟 |
| 空间导视与实验室门牌 | 可选 | 学院有独立建筑和多类空间资源，但第一轮应先服务数字传播与招生科研发布。 | 推迟 |
| 校园周边与纪念品 | 本轮不做 | 当前权威资料更集中于招生、科研、产业合作和活动传播，周边证据不足。 | 排除 |
| 传统招生宣传册大套装 | 本轮不做 | 学院强调快速迭代、项目制与数字传播，厚重纸质册不应成为首轮核心。 | 排除 |

## 自检
- 本计划是否规避了可预测的行业默认包？是。没有按“学校”默认加入校园主视觉、院徽盾牌、招生海报大套装或纪念品，而是从 RUNNING-GRID 与数字触点出发。
- 所有非Logo资产是否都关联到首要触点或所选策略？是。五个非 Logo 资产均服务官网、科研/开源发布、招生入口或数字 glyph 体系。
- 是否避免了默认添加 color-palette/campus/admissions/brochure/merchandise？是。没有把调色板、校园照片、传统招生册和周边列为生成资产；招生仅保留为第11章明确首要的数字入口模板。
- 整套资产是否像一个连贯系统而非互不相关的样品？是。Logo、网页首屏、科研列表、发布卡、项目入口卡和 glyph 系统都共享“底层网格—信号节点—metadata 层级”的同一规则。
