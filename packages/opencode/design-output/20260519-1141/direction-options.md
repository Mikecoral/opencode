# 视觉方向选项

## 方向一：RUNNING-GRID 可运行网格
- 核心主张：把创智学院设计成“正在运行的 AI 研究引擎”：一个可生成 SII、创/智抽象笔画、研究阵地和活动子符号的底层网格系统。
- 与简报的契合：直接回应“AI 前沿阵地、项目制与导师组、开源引擎、可变网格、真实系统”；适合官网科研进展、开源成果发布、TechFest 主视觉和实验室导视。MIT Media Lab 的网格派生逻辑和 Carbon 的主题/图层规则可作为方法参考。
- 潜在风险：最容易滑向评审提醒的“泛蓝绿科技视觉”；若只做发光节点、3D 线框和赛博背景，会削弱学院“共同体、青年创客、公共价值”的温度。
- 调色板取向：深色优先。深空蓝黑 `#07111F` 作主背景；智能蓝 `#176BFF` 作主操作/主信号；创智荧光绿 `#20E6A8` 作运行状态、开源发布、突破点；暖橙 `#FF8A3D` 只用于成果转化或社会价值节点；灰白 `#F5F7FA` 用于报告反相版。建立 token：Background / Layer / Signal / Running / Value / Text。
- 字体取向：中文为理性人文无衬线，正文克制；英文用紧凑 Grotesk，项目编号、模型版本、代码链接局部使用 Mono；标题可用可变字宽，但只在短标题和英文缩写中体现“压缩/展开”。
- 版式/构图：9×9 或 12×12 网格为基础，页面像系统仪表盘：左侧/顶部为导航与标签，主视觉为可运行 glyph 或推理路径，右侧嵌入论文、代码、导师、日期等 metadata。构图节奏为“密集信息区 + 高能信号点 + 留白冷却区”。
- 最适合的资产类型：主标与子标生成规则、科研方向 glyph、开源项目封面、论文/代码发布卡、官网科研列表、TechFest 屏幕与导视、实验室门牌。
- 负向引导：不要做传统盾徽、火炬、书本；不要使用无意义神经网络背景、霓虹粒子海、3D 芯片隧道；不要让蓝绿占满所有触点；不要牺牲中文长文可读性。

## 方向二：WEST-BUND-MAKER 滨江创客现场
- 核心主张：把创智学院呈现为“西岸 AI 创客社区”：更亮、更近人、更像实验正在发生的工作现场，而非遥远的黑盒科技机构。
- 与简报的契合：回应“科学家创客社区、青年、实战、从点子到产品、滨江实验楼、讨论室、草图/代码/demo 截图共存”；能平衡国家战略叙事与年轻共同体气质，特别适合招生营、开放日、导师招募和公众传播。
- 潜在风险：若处理过暖或过生活方式化，会变成创业园区/咖啡馆气质，削弱 AI 研究强度；照片素材质量不稳定时，系统容易松散。
- 调色板取向：浅色优先。背景以 `#F5F7FA`、`#FFFFFF`、浅混凝土灰 `#E8EDF3` 为主；深空蓝黑用于标题和页脚压舱；智能蓝用于链接、流程与导航；暖橙提高权重，用作招募、行动、Demo Day、产业转化；荧光绿仅作为“运行中/已开源/实验成功”的小标签。整体像白天实验室 + 滨江玻璃光，而非夜间控制台。
- 字体取向：中文人文无衬线占主导，字面开阔、亲近；英文 Grotesk 不宜过窄；允许手写批注、白板线条或草图式箭头作为辅助层，但必须与正式字阶并存。Mono 只用于代码片段和版本号。
- 版式/构图：采用“工作台”构图：大面积浅底、卡片化信息、照片/截图/白板草图叠放；日期与项目标签保持工程秩序，局部可用便签式高亮。摄影可裁切手部、讨论、屏幕、实验设备、夜间灯光和滨江空间，不追求宏大校园全景。
- 最适合的资产类型：博士遴选/夏令营视觉、开放日与 TechFest 现场物料、导师招募海报、学生项目故事、社媒长图、空间墙面、展板和成果路演模板。
- 负向引导：不要变成传统高校招生画册、合影墙、口号红底；不要过度使用卡通插画或低幼创客符号；不要把照片处理成滤镜大片，应保留真实实验质感但统一裁切和色温。

## 方向三：PUBLIC-ENGINE 公共价值引擎
- 核心主张：以“可信、开放、可传播的公共 AI 基础设施”为核心，用强编辑排版和数据/报告系统连接科研、产业与普惠价值。
- 与简报的契合：回应“既要国家战略，也要开源公共价值”“从不可能到可能，从可能到价值，从价值到普惠”；适合对外合作、年度报告、政策沟通、成果白皮书和官网专题。The New School 的品牌架构排版与 Carbon 的 productive / expressive 字阶可组合参考。
- 潜在风险：可能显得过于理性、公共机构化，弱化“敢闯无人区”的锐度；如果黑白红/蓝大字处理不当，会像国际艺术学院或咨询公司，而不是 AI 学院。
- 调色板取向：均衡但偏浅。白/灰白为主要阅读底；深空蓝黑作为标题、页眉和关键分隔；智能蓝作为结构色和链接；暖橙用于“价值/普惠/转化”章节；荧光绿降为数据状态色。比方向一更少发光，比方向二更少生活化照片。
- 字体取向：建立双层级：正式中文无衬线用于报告与政策沟通；英文/数字标题可使用可变宽度或压缩 Grotesk，制造强节奏。大标题允许极大字号和横向伸展，正文采用严谨字阶；Mono 用于数据表、模型名、GitHub、DOI、版本号。
- 版式/构图：强网格编辑系统：大标题 + 横线/竖线分栏 + 数据图表 + 引文短句；用“项目—导师组—企业伙伴—开源仓库—社会价值”的关系图替代抽象科技纹理。构图节奏更像高端研究报告、展览文字墙和会议议程系统。
- 最适合的资产类型：合作生态提案、年度影响报告、白皮书、政策沟通 PPT、成果转化专题页、TechFest 议程系统、媒体包和赞助伙伴墙。
- 负向引导：不要做成政府蓝白模板或咨询公司 PPT；不要用大段口号替代真实项目数据；不要滥用红色权威感；不要让图表只是装饰，应服务项目路径和成果证据。

## 推荐方向
- 推荐方向：优先探索“RUNNING-GRID 可运行网格”，并在第二轮把“WEST-BUND-MAKER 滨江创客现场”的摄影/现场资产作为温度层嵌入。
- 为何优先探索此方向：简报的核心差异化是新型 AI 研究型学院、项目制导师组、开源成果与产业转化枢纽；可运行网格最能形成可扩展的 Logo、子符号、官网封面和科研发布模板，解决长期一致性问题。单纯创客现场容易依赖照片质量，单纯公共价值引擎则不够年轻敢闯。
- 针对本简报应规避的方向：传统高校院徽/校训/红蓝政务风；三维赛博神经网络/芯片流光模板；纯创业园区生活方式摄影；只有大字口号、缺少科研 metadata 与开源入口的活动视觉。
