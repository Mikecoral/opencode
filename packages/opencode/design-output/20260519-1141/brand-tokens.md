# 品牌设计令牌：创智学院

## 色彩调色板
| 角色 | 名称 | 十六进制 | 用途 |
|------|------|---------|------|
| 主色 | 深空蓝黑 | #07111F | Logo 主形、深色界面背景、标题压舱色 |
| 强调色 | 智能蓝 | #176BFF | CTA、链接、主信号线、运行网格关键节点 |
| 背景色 | 背景灰白 | #F5F7FA | 官网、科研列表、发布卡的浅色背景 |
| 辅助色 | 冷层级灰 | #E8EDF3 | 卡片层、分割线、数据面板底色 |

**强调色纪律：** 本轮只使用一个强调色 `#176BFF`。简报中的荧光绿与暖橙作为未来状态/价值扩展色记录在研究背景中，但不进入本轮生成令牌，以避免蓝绿科技视觉泛化。

## 字体
| 角色 | 风格描述 | 字重范围 |
|------|---------|---------|
| 展示/Logo | 可变字宽的工程感 Grotesk / Neo-grotesk，与网格化中文抽象笔画兼容 | Bold / Black |
| 正文 | 理性人文无衬线，笔画清晰、字面开阔，适合中文长文和科研说明 | Regular / Medium |
| 说明文字 | 紧凑中性无衬线；模型版本、代码链接、论文编号可局部呈现 Mono 气质 | Light / Regular |

## 设计关键词（来自简报第7章节）
前沿信号、可变网格、青年合伙人、真实系统、开源引擎、滨江实验室、敏捷迭代、从0到1、智能涌现、价值普惠

## 文化意象（来自简报第5章节）
AI model layers and inference paths, modular nodes connected on a variable grid, West Bund riverside glass laboratory at night, maker workbench with code demos and system architecture sketches, open-source repository metadata and version tags

## 视觉研究输入
采用 `direction-options.md` 中用户认可并被推荐的“RUNNING-GRID 可运行网格”，对应 `research-signal` 方向。参考手法来自 MIT Media Lab 的底层网格派生逻辑、MIT Media Lab 官网运行态的研究数据库呈现、IBM Carbon 的色彩 token / 图层 / productive 字阶规则，以及 The New School 的可变字宽与多层级品牌架构。调色板取向以深空蓝黑、智能蓝、灰白图层为主，严格限制第二强调色；字体取向为中文理性人文无衬线、英文紧凑 Grotesk、版本号和开源链接局部 Mono。负向引导：不做传统盾徽、火炬、书本、红蓝政务风、无意义神经网络背景、霓虹粒子海、3D 芯片隧道，也不牺牲中文长文可读性。
