# Brand Design Brief: 创智学院

> 研究说明：公开检索中“创智学院”存在多个同名或相近项目，但最明确、信息最完整的指向为 **上海创智学院（官网 sii.edu.cn，英文版权名 Shanghai Innovation Institute）**。以下 brief 以该机构为主要研究对象；若客户实际为其他地区/主体的“创智学院”，则将其抽象为“面向中国当代创新、人工智能与产学研转化的新型教育学院”进行品牌设计。

## 1. Brand Overview / 品牌概览

创智学院应被理解为一所“新型教育科研与创新转化机构”，而不是传统培训学校或普通高校二级学院。公开资料显示，上海创智学院成立于 2024 年，位于上海徐汇北杨人工智能小镇/华发路 699 弄，聚焦人工智能前沿科研、博士人才培养、创新创业孵化与产业协同。官网内容包含“科研进展、产业合作、创新创业、学院导师、招生培养”等板块，当前传播关键词包括“开启改变世界的征途”“集不凡·创奇迹 / Calling for Marvellers”“一起做出改变世界的成果”。

其核心使命可概括为：培养具有国家情怀、厚实基础、创新精神、实践能力和产业转化能力的 AI 领军人才；通过“研、创、学”一体化机制，将科学研究、技术开发、创业实践和社会价值连接起来。与传统高校相比，它强调破界式选才、项目制实战、快速迭代课程、高密度算力与数据资源、师生共创、产业导师协同，以及从“不可能到可能、从可能到价值、从价值到普惠/善意”的价值路径。

品牌形象需要同时承载三重身份：

- **国家战略型教育科研平台**：可信、严谨、面向未来科技竞争。
- **AI 创新创业生态枢纽**：开放、敏捷、工程化、结果导向。
- **年轻顶尖人才的精神共同体**：好奇、敢闯、不循常规、愿意改变世界。

设计目标不是做一个“教育机构 logo”，而是建立一套具有科研高度、创业速度与青年能量的未来学院视觉系统。

## 2. Audience / 目标受众

**核心受众**

1. **AI 与交叉学科高潜人才**：博士生、硕士生、青年研究者、算法/系统/机器人/AI4S/生物医药智能等方向的极客型人才。他们追求顶级资源、真实问题、导师共创、技术影响力与创业可能。
2. **青年教师与科研带头人**：愿意加入新型科研组织、对传统评价体系不完全满足、期待跨学科协作和快速成果转化的人才。
3. **产业伙伴与科技企业**：AI 头部公司、硬科技企业、医疗/制造/金融/生命科学等应用场景方，关注科研成果落地、联合培养与技术转移。

**次级受众**

1. **政府、教育主管部门与基金资助方**：关注平台的战略价值、治理可信度、可持续成果与社会影响。
2. **合作高校与科研机构**：关注学院是否补充而非替代传统高校，是否能形成协同培养、共享资源与高水平产出。
3. **公众、媒体、家长与校友网络**：需要快速理解“这是一所什么样的学院”“为什么不一样”“是否可靠”。

**受众心理画像**

- 年轻技术人才喜欢清晰、强烈、可被社交传播的视觉符号，反感官样、陈旧、过度行政化的高校形象。
- 科研与政府受众需要秩序、权威、稳定与可信赖感，不能过度娱乐化、潮牌化。
- 企业伙伴看重效率、系统感、国际化表达和应用场景延展能力。

## 3. Positioning / 品牌定位

**建议定位语**：中国 AI 时代的研创型未来学院。

**一句话定位**：创智学院是连接顶尖人才、前沿科研与产业创新的新型 AI 教育科研平台，帮助“不凡之人”做出改变世界的成果。

**差异化支点**

- **不是传统高校**：从课程、考试、论文导向转向真实问题、影响力成果和项目负责人机制。
- **不是普通 AI 培训机构**：强调国家战略、博士级培养、科研基础设施、导师体系与前沿成果。
- **不是单纯孵化器**：创新创业建立在科研原创、工程验证与产业场景之上。
- **不是封闭研究院**：面向高校、企业、政府、创投与开源社区构建产学研创生态。

**竞争与参照环境**

- 国内高校人工智能学院：清华、北大、上海交大、复旦、浙大等高校 AI 学院具有学术权威，但视觉多偏高校传统体系。
- 新型研究机构：上海人工智能实验室、北京智源研究院、鹏城实验室等具有科研平台气质，视觉通常偏科技蓝、理性、实验室。
- 国际 AI/科技教育品牌：MIT Schwarzman College of Computing、Stanford HAI、DeepMind/Google Research/OpenAI 等具有开放、极简、系统化的现代科技语汇。

**设计机会**：在“高校庄重”与“科技公司前沿”之间建立第三种表达——更年轻、更开放、更有创造性，但仍具备国家级平台的可信度。

## 4. Personality / 品牌人格

**核心人格**：理性先锋、开放共创、敢破边界、负责任的未来主义。

**品牌价值观**

- **创造 / Create**：从 0 到 1，鼓励原创问题和原创路径。
- **智能 / Intelligence**：以 AI 为核心能力，也代表人的洞察、判断与责任。
- **奇点 / Breakthrough**：追求“不可能到可能”的关键跃迁。
- **共创 / Co-build**：导师、学生、产业与社会共同构建成果。
- **普惠 / For Good**：科技成果最终指向产业价值与社会善意。
- **可信 / Trustworthy**：科研伦理、技术安全、教育公信力不可牺牲。

**语气与表达**

- 中文：坚定、简洁、启发式，少用空泛宏大词，多用行动型动词。
- 英文：国际化、科研化、短句强节奏。
- 避免：低龄化“少儿编程感”、蓝紫霓虹泛滥的“普通 AI 培训感”、过度红金的行政宣传感。

## 5. Messaging / 传播信息架构

**主叙事**：创智学院不是把学生培养成标准答案的执行者，而是把他们推向真实世界的未知问题，成为能提出问题、构建系统、创造成果并承担责任的 AI 领军者。

**建议核心口号方向**

- 创造智能，智造未来
- 从不可能，到可普惠
- 集不凡，创奇迹
- 为改变世界的人，建立一所未来学院
- Research. Build. Venture. For Good.

**信息层级**

1. **愿景层**：面向人工智能时代，打造世界级创新人才与成果策源地。
2. **机制层**：研创学一体化、破界式选才、实战型导师、产业协同、高密度资源。
3. **成果层**：前沿科研、开源技术、创业公司、产业应用、社会影响。
4. **情感层**：这里欢迎天才、奇才、怪才、偏才；欢迎愿意把不可能变成价值的人。

## 6. Visual DNA / 视觉 DNA

**设计关键词**

1. 未来学院 Future Academy
2. 智能网络 Intelligent Network
3. 破界跃迁 Breakthrough
4. 研创一体 Research-to-Venture
5. 中国现代性 Contemporary China
6. 开放生态 Open System
7. 精密秩序 Computational Precision
8. 青年能量 Young Pioneers
9. 社会善意 Tech for Good
10. 国际化科研 Global Research

**视觉氛围**

- 整体应保持“冷静的科技秩序 + 明亮的创造能量”。
- 图形语言可采用模块化网格、节点网络、生成式线条、三维空间坐标、数据流、拓扑结构、光谱渐变等，但需克制，避免廉价赛博风。
- 版式应大留白、强对齐、数据化信息层级，兼容学术海报、招聘传播、会议系统与数字产品界面。
- 摄影风格建议真实、纪实、年轻：实验室、白板讨论、代码/模型训练、机器人/医疗/科学场景、导师学生并肩工作；减少摆拍领导合影作为主视觉。

## 7. Logo / Symbol Direction / 标志与符号方向

标志应同时具备中文识别、国际识别、小尺寸数字应用和空间导视可读性。建议提供“中文全称、英文全称/简称、图形符号、横版组合、竖版组合、社交头像版”的完整系统。

**可探索的符号概念**

1. **“创”与“智”的结构融合**：将“创”的开口、刀/新生意象与“智”的日/知结构抽象成几何符号，表达创造与智能的交汇。注意不要直接做复杂书法字，应现代、可缩放。
2. **SII / CZI 字母系统**：若采用官方英文 Shanghai Innovation Institute，可将 S、I、I 构造成递进通道、数据轨道或学院门廊，建立国际传播友好度。若客户更偏“Chuangzhi College”，可探索 CZ / ZHI 的字母化图形。
3. **“门 + 芯片 + 星火”**：学院作为进入未来科技的入口；芯片/算力代表 AI 基础设施；星火代表人才与原创突破。
4. **“拓扑节点”**：以中心节点向外连接高校、企业、科研、资本、社会，形成开放生态。适合延展为视觉纹样与动态图形。
5. **“跃迁箭头/折线”**：对应从不可能到可能、到价值、到普惠的阶段性跃迁，可形成品牌辅助图形。

**标志原则**

- 不建议使用具象大脑、灯泡、机器人头像、书本、博士帽等过度常见教育/AI 符号。
- 不建议复杂徽章化设计；如需体现学院权威，可设计“现代校徽式”备用版，但主标应更简洁。
- 图形应支持动态生成：节点可扩展、线条可流动、色彩可响应不同研究方向。

## 8. Color Strategy / 色彩策略

**推荐主色方向：深海科技蓝 + 创新电光青/绿 +  warm highlight**

- **深海蓝 / Institute Blue**：#071A3A 或 #0B1F4D。表达科研深度、国家平台可信度、夜间算力与探索未知。
- **智能青 / Intelligence Cyan**：#00C2FF 或 #20D6E8。表达 AI、数据流、开放连接和数字界面。
- **创生绿 / Innovation Green**：#00E08A 或 #21C77A。表达成长、生命科学、普惠价值与可持续创新。
- **星火橙 / Breakthrough Amber**：#FFB000 或 #FF7A1A。作为小面积强调，代表灵感、创业、跃迁时刻。
- **基础中性色**：近黑 #0A0D12、雾白 #F5F8FC、冷灰 #D7DEE8、石墨灰 #445064。

**色彩使用建议**

- 主视觉以深蓝/近黑为底时，青绿渐变形成高科技张力；适合发布会、官网首页、视频片头。
- 白底应用以深蓝文字和青绿强调，保持教育机构的清晰、可信与阅读性。
- 橙色只用于行动按钮、重点数据、奖项/成果高光，不宜大面积使用。
- 可为研究方向建立二级色：AI Infra 蓝、AI4S 绿、机器人紫、医疗智能红、创业橙，但必须受统一色彩系统约束。

## 9. Typography / Style / 字体与风格

**中文字体方向**

- 标题：现代黑体，结构硬朗但不冰冷，如思源黑体 Heavy/阿里巴巴普惠体 3.0/OPPO Sans/霞鹜文楷仅可作为特殊人文场景，不作为主字体。
- 正文：思源黑体、HarmonyOS Sans SC、阿里巴巴普惠体等高可读无衬线。
- 可定制字标：对“创智学院”四字进行几何化定制，保留中文力量感；笔画可有“切角、开口、连接节点”细节，但不得牺牲识别。

**英文字体方向**

- 标题/品牌：几何或 neo-grotesk 无衬线，如 Space Grotesk、Neue Haas Grotesk、Inter、Suisse Int’l 方向。
- 数据/代码场景：可配等宽字体，如 JetBrains Mono / IBM Plex Mono，用于科研数据、程序、坐标与注释信息。

**版式原则**

- 高密度信息要用网格管理，体现“算力、研究、系统”的专业性。
- 招生与人才传播可用更强标题、更大字号、更有冲击的短句。
- 学术与政府材料需保持规范：标题醒目、正文稳定、信息层级清楚。

## 10. Required Assets & Constraints / 必需资产与约束

**必需交付资产**

1. 主标志：中文全称、英文全称、简称/图标版、横竖组合、反白版、单色版。
2. 品牌规范：安全区、最小尺寸、错误使用、色彩数值、字体规范、版式网格。
3. 辅助图形：节点网络、跃迁路径、生成式纹样、研究方向图标体系。
4. 数字应用：官网首页视觉、移动端头图、公众号封面、小程序/系统图标、社交头像、视频片头/片尾基础动效建议。
5. 招生与活动物料：博士遴选营海报、开放日主视觉、讲座/沙龙模板、TechFest/未来大会视觉延展。
6. 办公与传播：PPT 模板、信纸、名片、邮件签名、证书、工牌、文件夹、成果报告封面。
7. 空间与环境：楼宇门头、导视系统、实验室门牌、会议背景板、展墙、成果展陈信息牌。
8. 周边与社群：T 恤、卫衣、贴纸、徽章、帆布袋、笔记本、迎新礼包，服务于青年人才社群归属感。

**设计约束**

- 若客户已有官方 logo/校名标准字，需先确认是“升级优化”还是“全新设计”；若仅做活动或子品牌，应避免与现有校级标识冲突。
- 需兼容中文为主、英文并行的双语传播；英文命名需客户确认：Shanghai Innovation Institute / Shanghai Chuangzhi College / Chuangzhi Academy。
- 禁止使用过度泛化的 AI 图标库元素，如大脑电路、发光机器人、灯泡书本组合。
- 必须保证政府文件、学术论文发布、国际会议、创业路演、校园社群五类场景都能使用。
- 色彩需符合无障碍对比度，深色背景上的青绿文字不宜用于长正文。
- 动态/生成式视觉可以作为亮点，但静态 logo 必须在黑白、刺绣、门牌、印章、小尺寸 favicon 中成立。
- 视觉应呈现“年轻但不轻浮、科技但不冰冷、权威但不官僚、国际但有中国语境”。

## Supplement. Signature Events & Poster Themes / 标杆性活动与海报主题素材

以下内容用于后续生成复杂 poster、活动主视觉、系列模板和动态传播素材。公开信息中可见的创智活动具有“硬核科研 + 年轻社群 + 产业转化 + 开放生态”的复合气质，视觉系统应能支持年度大会、讲坛沙龙、训练营、创业路演、成果发布等多种复杂信息场景。

### A. 已有公开活动信号

1. **SII TechFest / 创智未来大会**
   - 已见主题口号：**“以梦为炬，创想燎原”**。
   - 相关模块：智绘前沿 Workshop、创智未来大会、创智开放日、AI 星耀创享汇。
   - 活动类型：年度科技节、成果发布、开放日、Workshop、生态发布、颁奖互动。
   - 海报钩子：AI 前沿星图、三日议程时间轴、成果发布矩阵、闭门研讨模块、算力联盟、创业企业墙、开放日互动贴纸。

2. **“创奇·智能新引擎”成果交流会**
   - 主题方向：科研智能全栈体系、有组织的科研、AI 科学家、能动科研。
   - 关键词：科学智能基础设施、创智数据工厂、TaaS 训练即服务、科研驾驶舱、自驱动实验室、AI 安全矩阵。

3. **“研创学”生态交流分享会**
   - 已见主题口号：**“创育不凡，智启万象”**。
   - 核心概念：以“创”为核心的研创学一体化；研究、创新、学生三条管线；Researcher Founder。

   - 海报钩子：三环生态系统、学生到实验室再到产业的闭环、创培/创孵/创投/创联/创赛路径、从 0 到 1 的跃迁路径。

6. **创智未来之星创业大赛 / 孵化项目开放日**
   - 主题方向：以赛引才、以赛选才、以赛育才；从实验室代码到市场价值。
   - 活动形态：路演、Demo Booth、投资人沙龙、总决赛、项目开放日。
   - 海报钩子：星轨、路演舞台、项目墙、展区地图、投资雷达、未来产业图谱。

7. **FDE 前沿部署工程师培训**
   - 主题方向：破解 AI 落地“最后一公里”；让技术人才进入真实业务现场。
   - 关键词：培养矩阵、百千万工程、智能体应用、全栈交付、驻场式迭代。
   - 海报钩子：城市“最后一公里”路径、工程师战术地图、智能体工厂、客户现场与指挥舱双场景。

8. **无界沙龙**
   - 已见案例：创智无界沙龙“对话姚明”，呈现科技、体育与人文的跨界碰撞。
   - 核心气质：突破行业边界，碰撞思维火花。
   - 海报钩子：人物剪影、运动轨迹、数据流、跨界符号碰撞、AI + X 的混合图形语言。

### B. 可延展的品牌标杆活动方向

这些不是已确认的官方固定活动名，而是基于创智现有气质可发展出的活动视觉系列方向，适合做后续 poster 提案或年度传播规划。

1. **AI 科学家之夜**：面向科研成果、青年博士、AI4S 项目发布；视觉可用深色星空、实验光束、公式云和科学仪器轮廓。
2. **创智未来产业 Demo Day**：集中展示师生创业与产业转化；视觉可用项目矩阵、城市产业地图、投资雷达和路演舞台。
3. **FDE 真实场景挑战赛**：企业真实需求发布与限时解决方案；视觉可用任务地图、工单界面、现场部署动线和智能体工厂。
4. **科学智能百题路演**：围绕 AI + 生命科学、材料、气象、能源、机器人等真实科学问题；视觉可用蜂巢、星群、百题卡片墙。
5. **无界人物系列**：邀请体育、艺术、金融、医疗、制造等领域领军者；视觉可延续 AI + X 的跨界碰撞语言。
6. **创智开放实验室周**：面向公众、学生与合作伙伴开放科研空间；视觉可用透明实验室、可视化仪器、互动贴纸墙和路线地图。

### C. Poster 母题库

后续做复杂 poster 时，优先沉淀并复用以下母题：**引擎、星火、驾驶舱、数据工厂、实验闭环、智能体网络、机器人身体、分子宇宙、算力集群、上海科创城市网格、青年科学家群像、星海航线、项目矩阵、跨界碰撞、任务地图**。

复杂 poster 应避免只做抽象渐变背景。每张海报至少要有一个明确的“信息结构钩子”：议程时间轴、成果矩阵、生态地图、技术架构、人物关系、路线地图、任务卡系统、项目墙或实验闭环。这样既能承载真实活动信息，也能保持创智“前沿、实战、年轻、硬核、开放、能动、产业化”的品牌气质。

**最终创意方向建议**

以“智识跃迁的开放网络”为核心概念：主符号由开放的几何门廊/节点网络/跃迁折线构成，象征学院把人才从知识学习推向真实创造；色彩以深蓝建立科研与机构信任，以电光青绿表达 AI 能量，以星火橙点亮突破瞬间。整套系统应像一个可生长的智能生态，而不是一个静止校徽。
