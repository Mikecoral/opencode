# 创智学院品牌形象设计简报

> 研究说明：公开检索中“创智学院”最明确、权威且活跃的结果指向“上海创智学院 / Shanghai Innovation Institute, SII”。本简报以“上海创智学院”为主要对象进行品牌策略与视觉方向研究；如委托方实际为其他同名机构，可保留“创智学院”这一未来教育与创新学院定位，将地域与机构数据替换即可。主要参考来源包括上海创智学院官网、学院概况页、招生与科研动态、澎湃新闻报道及公开招生资讯。

## 1. 品牌语境 Brand Context

上海创智学院是 2024 年成立、位于上海徐汇区华发路 699 弄 3 号 / 北杨人工智能小镇的新型高等教育科研机构。它不是传统意义上的单一大学学院，而是由顶尖高校、科研机构、头部企业共同参与建设的 AI 领军人才培养与科研创新平台。学院官网英文版权名为 **Shanghai Innovation Institute**，常用缩写 **SII**。

学院的核心叙事不是“上课—考试—毕业”，而是“前沿信号—真实项目—系统攻关—产业转化”。官方表述强调“以学生为中心、以前沿为牵引”，通过“超高规格师资、超常措施培养、超凡条件保障”探索中国特色 AI 领军人才培养方案。公开报道显示，学院链接 31 所头部高校，拥有全职全时导师、兼职导师、产业导师与企业资源，并建设算力、数据、实验平台、创业孵化等基础设施。

当前品牌机会在于：创智学院具有国家战略、上海科创、AI 基础设施、青年科研创业者四重身份，但视觉上容易被误读为普通高校、培训机构或泛科技园区。新品牌形象需要建立一种“新型科研操作系统”的可信感：既有公共教育机构的庄重与责任，也有前沿实验室的速度、开放性和工程气质。

设计应抓住三个真实差异：

- **有组织的前沿科研**：不是展示 AI 概念，而是展现算力、数据、模型、实验、治理之间的完整链路。
- **破界式人才培养**：面向能定义问题、组织资源、直面无人区的青年研究型创业者。
- **从不可能到普惠**：技术目标并非炫技，而是让科研成果从可能性变为社会与产业价值。

## 2. 目标受众 Target Audiences

### 核心受众

1. **顶尖博士生与准博士生**  
   来自清华、北大、复旦、交大、浙大、中科大等参建高校及优秀科研院所；年龄多为 20–30 岁；关注导师、算力、数据、研究自由度、项目价值、创业可能性。视觉上需要让他们感到“这里不是官样宣传，而是真正能做事的前线”。

2. **青年 PI、全时导师、博士后与全球科研人才**  
   他们希望加入一个可快速组织资源、跨学科协作、容忍失败但追求高影响力的机构。品牌需要表现专业可信、开放自治、资源密度高，而不是行政化高校形象。

3. **产业伙伴、AI 企业、创投机构**  
   关注成果转化、联合实验室、项目验证、创业孵化。视觉表达要让对方相信学院具备工程落地、组织效率与风险治理能力。

### 重要次级受众

4. **政府、教育主管部门、上海科创生态相关方**  
   需要看到国家战略价值、公共性、制度创新与上海全球科创中心气质。视觉上不能过度商业化或娱乐化。

5. **公众、媒体、家长与社会舆论**  
   他们对“新型学院”“AI 天才培养”“不设强制学制”等模式可能好奇也可能存疑。品牌需降低误解，建立透明、严谨、可验证的信任感。

6. **国际合作对象**  
   包括海外高校、实验室、会议、学者。需兼容中英文系统，避免仅靠中文书法或本土教育符号。

## 3. 品牌定位 Positioning

### 建议定位语

**创智学院：面向 AI 时代的科研与人才创新操作系统。**

### 品牌角色

- 不是普通高校：它是跨高校、跨产业、跨学科的前沿组织平台。
- 不是培训营：它培养能在真实问题中形成原创成果的人。
- 不是孵化器：它从科研源头、算力数据、实验闭环到资本转化形成完整系统。
- 不是科技公司：它保有教育公共性、国家战略使命与长期主义。

### 差异化坐标

- 相比传统大学学院：更敏捷、更项目制、更贴近 AI 产业主战场。
- 相比企业研究院：更开放、更重视人才培养与公共科研价值。
- 相比创新创业基地：更硬核科研、更高技术门槛、更强学术与工程基础设施。
- 相比泛 AI 教育品牌：更少“未来感装饰”，更多“系统、证据、现场、成果”。

### 核心品牌主张

**把不可见的前沿信号，组织成可运行的科研系统；把个体天赋，锻造成改变世界的 AI 创造力。**

## 4. 品牌个性 Brand Personality

- **前沿但克制**：不做赛博霓虹式炫技，以可验证的系统感体现先进性。
- **年轻但不轻浮**：承认青年主角，语言有动能，但视觉仍有机构级稳定性。
- **理性但有温度**：强调算力、数据、模型，也要呈现学生自主、导师共创、普惠价值。
- **开放但有边界**：跨学科、跨机构协同，同时体现安全、治理、评价标准。
- **中国语境下的国际化**：具备上海与中国 AI 战略气质，但不依赖红金、校徽、祥云等传统符号。

### 语气建议

关键词：真实、直接、行动导向、问题导向、可信。  
避免：空泛口号、鸡血式招生、互联网黑话堆叠。

可使用表达：

- “从前沿信号到真实系统”
- “在无人区组织行动”
- “研创学一体化”
- “让科研可运行、可迭代、可转化”
- “从不可能到可能，从可能到价值，从价值到普惠”

## 5. 视觉 DNA Visual DNA

### 核心视觉关键词

1. **前沿信号**：细微但高价值的方向感，适合转化为波形、扫描线、坐标点、动态光标。
2. **科研链路**：算力—数据—模型—实验—产业的连续结构，适合模块化线框与层级图形。
3. **无人区坐标**：探索未知而非装饰未来，适合网格、坐标轴、等高线、实验标记。
4. **系统生长**：从单点到网络、从原型到生态，适合可扩展图形语法。
5. **青年主战位**：应出现“人作为主体”的比例关系，而非只有机器和芯片。人物影像以 2–4 人真实工作场景为主：白板推演、代码审阅、实验设备调试、导师站立讨论；人物占画面 20–35%，避免正面摆拍、握手、VR 头显、商业宣传笑脸。
6. **上海西岸 / 北杨新场景**：玻璃幕墙、滨江、工业更新、AI 小镇，可作为摄影与空间语言参考。
7. **可验证推理**：通过标注、版本号、实验记录、代码片段式排版建立可信感。
8. **普惠价值**：用清晰、开放、明亮的留白平衡硬核科技感。

### 图形语言建议

- 以“动态坐标网格 + 任务节点 + 实验标注”形成主视觉系统。
- 建立一套可生成的“前沿信号纹理”：由不规则数据点、短线段、局部高亮组成，避免普通电路线。
- 版面应像科研控制台与学术海报的结合：有结构、有层级、有可读性，而非满屏渐变。
- 摄影风格偏纪实：导师讨论、学生白板推演、机房、实验台、开放空间、夜间研究场景；避免摆拍握手、戴 VR 眼镜、蓝色人脸 AI 图。

## 6. 标志 / 符号方向 Symbol / Mark Direction

### 总体方向

标志应体现“创智”二字的双重含义：**创造 intelligence，不是消费 intelligence；组织 intelligence，不是包装 intelligence。** 建议围绕 SII / 创智 / 科研链路建立一个高度可扩展的核心符号。

### 首选路线

主标志优先采用 **“SII 三段式开放链路”**：三段错位模块由左下向右上推进，代表 **Signal / Infrastructure / Impact**，也可对应 **Student / Science / Industry**。它不是闭环圆、不是神经网络球、不是雷达屏，而是一条仍在向前推进的开放科研链路。中文“创”字的工程化切口可作为辅助图形语法，用于版式分割、标题容器和动态纹理，不作为主标。

### 可探索概念

1. **“SII 三段式链路”标志（首选）**  
   将 SII 抽象成三段相互错位连接的模块，分别代表 Student / Science / Industry 或 Signal / Infrastructure / Impact。三段之间不是闭环圆，而是向前推进的开放链路，体现“从可能到价值到普惠”。

2. **“创”字结构的工程化重构**  
   不做毛笔字。提取“创”字中刀部与仓部的结构关系，转化为切入、开口、突破边界的几何形。可形成一个带有“切口”的方形坐标场，象征破界式选才与开辟无人区。

3. **“智核 / 任务节点”符号**  
   以一个中心节点连接多层外部系统，但避免普通神经网络图。节点应更像科研任务板：有主节点、版本分支、实验反馈回路，可用于动效与应用系统。

4. **“前沿信号雷达”符号**  
   用非完整圆弧与坐标点表达前沿信号捕捉，但必须克制，不做军事雷达或科幻 HUD。适合招生营、TechFest、科研发布会子品牌延展。

### 标志使用要求

- 中文“创智学院”与英文 “Shanghai Innovation Institute / SII”需形成严谨组合。
- 小尺寸场景下应可识别，适合网站 favicon、胸牌、PPT 页脚、系统入口。
- 可设计静态标志 + 动态生成图形系统：标志稳定，辅助图形可根据科研方向变化。
- 禁止把三段链路做成闭合校徽、圆形章、抽象大脑、发光芯片、星球轨道或军事雷达。

## 7. 色彩策略 Color Strategy

### 色彩原则

避免泛科技品牌常见的“深蓝 + 霓虹蓝紫渐变”单一路径。创智学院需要更像“科研现场 + 上海新城 + 智能基础设施”，应在冷静底色中加入具有能量的信号色。

### 建议主色

- **创智深墨蓝 / Research Navy**：#071827 或 #0B1F2A  
  用于机构级权威、夜间科研、深度思考。比纯黑更有温度，比政务蓝更前沿。

- **北杨银灰 / Infrastructure Silver**：#D7DEE4 / #AAB4BC  
  表达基础设施、玻璃幕墙、实验设备与工程精密感。

### 建议信号色

- **前沿青绿 / Signal Teal**：#00C2A8  
  品牌唯一主 accent，占单张画面 5–8%。代表前沿信号、数据流、生命科学与开放协作。避免荧光过度，可用于节点、按钮、高亮。

- **创奇橙 / Proof Orange**：#FF6A2A  
  仅用于招生 CTA、成果转化、deadline 或关键 proof point。单张画面最多 1 处，避免与青绿争夺主视觉。

- **智能紫蓝 / Model Violet**：#5B5FF0  
  只用于 AI 模型子系统标签、技术图例或夜间界面的局部模块，不参与主品牌海报背景或大面积渐变。

### 中性色与背景

- **实验白 / Lab White**：#F7F9FA，用于长文、招生简章、学术内容。
- **数据黑 / Data Black**：#111315，用于高对比信息图。

### 色彩比例

70% 深墨蓝 / 实验白基础，20% 银灰结构，5–8% 青绿主信号，0–3% 橙色或紫蓝场景副色。让品牌看起来“有能量但不吵”。

## 8. 字体方向 Typography Direction

### 中文字体

- 主系统建议锁定 **思源黑体 / Source Han Sans SC**。主标题使用 700/800 字重，字距可略紧（约 -0.02em），保持机构级稳定与现代感。
- 重要标题可定制字形：对“创”“智”关键笔画做微小切角或开口处理，呼应“破界 / 开源 / 前沿信号”。不要做过度变形，以免降低机构可信度。
- 正文需优先保证科研与招生文本可读性，行距充足，避免炫技排版。

### 英文字体

- 主系统建议锁定 **IBM Plex Sans**，用于 SII、项目名、英文标题、数字解释。
- 代码、版本号、科研标注锁定 **IBM Plex Mono**。英文小标签使用 Mono Medium，全大写，字距约 +0.08em；等宽字体只用于标注层，不应替代主字体。
- 正文使用 400/500 字重，行距 1.45–1.6；复杂 poster 的数字可使用 IBM Plex Sans 700/800，配 Mono 证据标签。

### 排版气质

- 建立“学术海报 + 系统界面”的混合秩序：大标题简洁有力，副标题解释清楚，数据块、项目块、导师块有明确层级。
- 用英文小标签增强国际化与系统感，例如：SIGNAL、SYSTEM、PROTOTYPE、IMPACT、SAFETY、CO-CREATE。

## 9. 应用场景 / 触点 Applications & Touchpoints

### 数字触点

- 官网首页与栏目页：需要建立“研究进展 / 招生培养 / 产业合作 / 人才引进”的统一信息架构与视觉模块。
- 招生系统与报名页：强调可信、清晰、低摩擦；用信号色突出时间节点、考核流程、材料状态。
- 科研成果页面：适合用“项目卡片 + 技术链路图 + 影响力数据”展示，避免新闻稿式长图堆砌。
- 社交媒体封面：形成可快速识别的标题模板、日期模块、项目标签系统。
- PPT / Keynote 模板：学院高频用于报告、路演、发布会，应提供深色发布会版与浅色学术版。

### 招生与活动

- 夏令营、春季营、金秋营视觉系统：不做“青春校园风”，应做“任务挑战 / 实战营地 / 前沿试炼”的严肃而有吸引力的系统。
- TechFest / 创智未来大会：可使用动态前沿信号纹理与项目地图，形成年度事件识别。
- 胸牌、录取通知、营员包：使用坐标编号、任务标签、个人研究方向字段，增强归属感。

### 空间与环境

- 校园导视：基于坐标网格和模块编号，呼应实验室与科研操作系统；避免传统校园碑刻风。
- 玻璃幕墙 / 大厅：可设计动态数据墙，展示实时讲座、项目进展、科研方向，而非单纯口号墙。
- 教室、讨论室、机房、实验区：用不同信号色区分功能区，并保留足够白墙用于推演和记录。

### 机构传播与合作

- 联合实验室牌匾、合作证书、成果发布会背板：需兼容政府、企业、高校多方 logo，品牌系统应有严格网格与留白规则。
- 招聘与人才引进：延续官网“Calling for Marvellers / 集不凡·创奇迹”的探索气质，但视觉更聚焦“做出改变世界的成果”。
- 创业孵化品牌：可发展子系统，如 SII Venture / 创智未来中心，用橙色作为行动与转化标识。

## 10. 反套路约束 Anti-generic Constraints

为避免落入普通教育科技品牌套路，设计必须遵守以下约束：

1. **禁止普通 AI 图标堆叠**：不要用大脑、电路板、机器人头像、发光芯片、云端节点作为主标志。
2. **禁止校徽化复古模板**：不要使用盾牌、麦穗、书本、火炬、飘带、圆形校章作为核心视觉。创智学院是新型机构，不应假装百年大学。
3. **禁止过度赛博朋克**：少用霓虹紫蓝大渐变、3D 发光球、黑底满屏粒子。前沿不等于夜店科技感。
4. **禁止培训机构感**：不要使用卡通学生、手绘灯泡、成长阶梯、奖杯、冲刺班式红黄 CTA。
5. **禁止空洞未来口号**：如“赋能未来”“智启未来”“AI 改变世界”若无具体项目支撑，不应作为主视觉核心。
6. **禁止只有机器没有人**：创智的主角是青年科研者、导师与协同网络。视觉要保留人的尺度与行动现场。
7. **禁止把“中国风”表面化**：不使用祥云、水墨、篆刻来表达国家战略；可用秩序、责任、长期主义体现中国语境。
8. **禁止单一蓝色政务科技感**：蓝色可用，但必须有独特的信号色与材料感，避免与高校官网、政府平台同质化。
9. **禁止复杂到不可执行**：标志与图形系统必须能落地在官网、PPT、胸牌、导视、招生海报等高频场景。
10. **禁止视觉脱离科研事实**：每个关键视觉概念应能对应学院真实资产：算力、数据、导师组、项目制、前沿课题、创业孵化、安全治理。

### 设计成败判断

如果设计看起来像“普通 AI 培训品牌”，失败。  
如果设计看起来像“传统大学新学院”，不够。  
如果设计让人感觉“这里是一套能组织天才、资源与真实问题的科研操作系统”，方向正确。

## 11. 海报素材库 / Poster Data Bank

> 使用原则：以下素材优先来自上海创智学院官网与公开媒体报道；涉及百度百科、新闻聚合或第三方转述的数据，已标注“待核实”。海报制作时建议把“硬数据 + 项目名称 + 时间节点 + 官方原话”组合成信息层，而不是只做抽象科技感。

### 数据使用状态规则

为避免复杂 poster 误用未核实数据，所有数据在正式出街前按以下等级处理：

- **Official / Can publish**：来自学院官网正文、官方页面或官方活动日历。可用于正式设计，但仍建议人工校对文字。
- **Public media / Draft only**：来自权威媒体报道或公开报道口径。可用于方案稿、内部提案或视觉样张；正式发布前需院方确认。
- **Third-party summary / Draft only**：来自搜索摘要、百科、新闻聚合。只可作为视觉草图灵感，不可作为最终海报文字。
- **Needs client confirmation / Do not render final text**：存在口径差异、年份差异或数量可能更新。不得作为最终大数字或主标题。

生成阶段不得渲染真实电话、完整地址、个人姓名。视觉样张中使用 `[OFFICIAL PHONE]`、`[VENUE]`、`[SPEAKER]`、`[DATE]`、`[URL]` 占位，最终人工排版确认后再替换真实信息。

复杂 poster 每张只允许 1 个主标题、1 个核心大数字组、3–7 个模块节点、1 条证据层；不得同时展示超过 9 个独立数据点。所有数据文本必须来自本素材库，并在交付说明里注明状态等级。

### I. 复杂 poster 的版式建议：如何把事实转成视觉

1. **年度成果海报**：以“创奇·智能新引擎”为主标题，中心放“科研智能全栈体系”，周围七大成果环绕；每个成果只放 1 个关键词 + 1 个数字（如 195 家、3.4 亿、5000+/day）。
2. **招生海报**：上半部放“破界、实战、超常规”，中部用流程线呈现材料评审、Prompt / 数理 / 代码 / 48h 实训 / 导师面试，底部放地址、报名系统（待核实）与时间窗口。
3. **导师资源海报**：用 81 / 130+ / 120+ / Avg.36 做四个大数字，背景用导师组网络；所有数字标“待核实”直到院方确认。
4. **科研突破海报**：采用“微观尺度 + 长周期 + 高影响”的反差结构，例如 `1μm / 12 days / 87.52%`；适合用显微图、实验曲线、论文 DOI 作为证据层。
5. **开源成果海报**：MOSS-TTS-Nano 用开发者界面风：0.1B、20 languages、48kHz、100ms、CPU、GitHub/HuggingFace 链接二维码。
6. **活动日历海报**：以 `SII Calendar` 为统一栏目，按主题色区分 AI Infra、Scientific AGI、Robotics、AI Safety、Audio Intelligence；保留“时间 / 地点 / 主讲人”三项硬信息。
