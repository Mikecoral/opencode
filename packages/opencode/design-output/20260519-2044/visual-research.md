# 创智学院 / Shanghai Innovation Institute 视觉研究

> 研究基准：本文件以 `brief.md` 的修订定位为依据——“面向 AI 时代的科研与人才创新操作系统”，并引用海报素材库中可公开使用或需确认的数据结构：SII / Shanghai Innovation Institute、北杨人工智能小镇、2.7 万㎡科研现场、导师组培养、AI Infra 春季营 500+ 申请 / 48h 实训、创奇·智能新引擎七大成果、科研驾驶舱、数据工厂、NEXChem、NEXMed、AI 安全矩阵等。视觉研究目标不是生成设计，而是识别同类机构的视觉惯性与可转化原则。

### 类别视觉景观总结

1. **高校与研究机构主流仍是“母品牌色 + 字标锁定 + 新闻摄影”**：MIT、Stanford、AIR 都依赖大学资产建立信任。优势是权威，风险是像传统学院官网。
2. **AI 研究院普遍使用蓝、黑、白、灰作为安全色**：上海 AI 实验室、IBM、DeepMind 局部都以蓝系或中性色建立技术可信。若创智也只用深蓝/亮蓝，会被归入“政务科技平台”。
3. **真正有差异的系统来自“可扩展图形语法”**：MIT Media Lab 用同一 7×7 网格生成 23 个研究组 glyph；IBM 用 2x Grid、Plex、蓝色核心和严密色阶统一复杂生态。这比单个酷 logo 更适合创智的多项目、多导师、多成果。
4. **人物摄影是 AI 机构避免冰冷的关键**：Stanford HAI、Vector、Mila 都大量出现学生、研究者、会议、讨论场景。创智海报素材库也强调人物占画面 20–35%、白板推演、代码审阅、实验设备调试。
5. **活动海报常见两极：学术黑白字排 vs 科技蓝紫炫光**：Yale Architecture 的黑白全字海报代表高识别学术传统；AI 科技活动常落入霓虹粒子、芯片、脑图。创智应走第三条：科研控制台 + 学术海报 + 证据标注。

### 在该类别中会显著站出来的做法

- 不使用大脑、机器人脸、芯片、电路板，而使用**科研链路 / 任务节点 / 版本标注 / 实验证据层**表达 AI。
- 把“2.7 万㎡、48h、500+、195 家、3.4 亿、5,000+/day、SII-007、MOSS-TTS-Nano”等数据做成**可核验的信息图层**，而不是当口号背景。
- 建立“标志稳定 + 图形可生成 + 海报可编码”的系统：不同栏目（SII Calendar、AI Infra、创智沙龙、成果交流会、人才引进）用同一语法延展。
- 使用真实科研现场影像：白板、机房、实验台、导师讨论、夜间研究，而非 AI 合成的蓝色人脸。

## 3. 反泛化观察：必须避开的 AI 教育套路

1. **不要把“AI”画成脑、芯片、线路板、机器人脸**：竞品中更成熟的机构都依靠系统、项目、数据、人物和规范建立可信，而不是图标堆砌。
2. **不要做传统高校校徽化**：创智不是百年大学学院；盾牌、书本、麦穗、火炬会误导为常规学院。
3. **不要满屏蓝紫霓虹渐变**：上海 AI 实验室、IBM、DeepMind 已占据蓝色科技语境；创智需要“深墨蓝 + 银灰基础设施 + 青绿信号”的克制识别。
4. **不要只有宏大口号，没有证据层**：海报素材库有大量强事实，优先使用 `48h Challenge`、`2.7万㎡`、`Compute → Data → Model → OS → Lab Loop → Safety`、`SII-007`、`60万+ downloads` 等。
5. **不要把青年人才表达成培训班**：避免卡通学生、奖杯、冲刺班 CTA。应呈现“年轻科研者在真实项目主战位”的现场。
6. **不要把合作生态做成 logo 墙**：AIR 等机构常见伙伴密集陈列；创智应转译成“问题—资源—项目—验证—转化”路径图。
7. **不要复杂到无法执行**：官网、招生长图、SII Calendar、PPT、胸牌、导视都需要同一系统落地。
