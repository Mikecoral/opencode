# 创智学院 / Shanghai Innovation Institute 视觉方向选项

> 三个方向均遵守简报反套路约束：不使用大脑、霓虹赛博渐变、盾牌、书本、机器人脸、电路板 logo；均以“科研与人才创新操作系统”为核心，只是表达侧重点不同。

## 方向一：开放链路 Open Research Chain

**核心 idea**：把创智定义为一条仍在推进的科研链路：Signal / Infrastructure / Impact，Student / Science / Industry，形成从前沿信号到社会价值的开放路径。

- **Logo 路线**：优先发展“SII 三段式开放链路”。三段错位模块由左下向右上推进，可在小尺寸中识别为 SII，也可在系统中拆分成栏目节点；避免闭环圆、轨道、芯片线。
- **色彩使用**：深墨蓝 `#071827` / 实验白 `#F7F9FA` 为底；银灰 `#D7DEE4` 建结构；前沿青绿 `#00C2A8` 只作 5–8% 节点高亮；创奇橙 `#FF6A2A` 仅用于 deadline、入营、成果转化 CTA。
- **字体**：中文思源黑体 700/800 做主标题，英文 IBM Plex Sans；证据标签、版本号、流程编号用 IBM Plex Mono 全大写小标签，如 `SIGNAL / INFRA / IMPACT / 48H / v0.3`。
- **海报系统**：采用“主标题 + 三段链路 + 证据层”模板。招生海报可把材料评审、数理考试、代码机考、48h 实训、导师面试做成开放路径；成果海报把 Compute → Data → Model → OS → Lab Loop → Safety 做成链路图。
- **应用**：官网首页导航、SII Calendar、招生长图、PPT 封面、胸牌编号、导视楼层编号、成果交流会背板都可共用链路模块。
- **优势**：最贴合简报首选标志路线；机构级、系统化、易扩展，能把教育、科研、产业放入同一语法。
- **风险**：若线段过细或节点太多，容易像普通流程图 / SaaS 产品后台；必须保持强主标、充足留白和少量高亮。

## 方向二：科研驾驶舱 Research Cockpit

**核心 idea**：把创智塑造成“真实科研任务的控制台”——所有视觉都像可验证、可追踪、可迭代的科研操作界面。

- **Logo 路线**：以“任务坐标 / 光标切口”形成 SII 或“创”的工程化开口：不是电路，而是一个可定位的任务窗口；标志边缘可有精确切角，呼应破界与无人区坐标。
- **色彩使用**：数据黑 `#111315` 与深墨蓝 `#0B1F2A` 为深色主场景；Lab White `#F7F9FA` 作浅色学术版；青绿 `#00C2A8` 作实时信号；智能紫蓝 `#5B5FF0` 仅给模型/AI Infra 模块；橙色只标警示、截止、转化。
- **字体**：更强调等宽字体层：IBM Plex Mono 用于时间、地点、版本、数据状态；主标题仍用思源黑体重字重。版式可出现类似 `STATUS: OFFICIAL / MODULE: NEXMED / DATA: 5000+/DAY` 的证据条。
- **海报系统**：像科研控制台与学术海报结合。每张复杂海报只允许 1 个主标题、1 组大数字、3–7 个任务模块、1 条来源/状态栏。AI Infra 可做 `500+ Applicants / 48h Challenge / Coding Exam`；创奇·智能新引擎可做七大模块 dashboard。
- **应用**：科研成果页、开源项目页、数据工厂 / 科研驾驶舱专题、TechFest 大屏、实验室导视、PPT 技术章节、GitHub / HuggingFace 项目封面。
- **优势**：最能区隔传统高校和培训机构；能承接海报素材库中大量技术数据，显得硬核、可信、前沿。
- **风险**：容易过冷、过技术、像网络安全或金融交易终端；需要加入真实人物现场和明亮留白，避免“只有机器没有人”。

## 方向三：青年前线 Young Frontier Lab

**核心 idea**：把创智的主角从“AI 技术”转向“能组织资源、定义问题、进入无人区的青年科研者”，形成严肃但有动能的招募型机构视觉。

- **Logo 路线**：主标仍保持简洁 SII / 创智字标，但辅助符号采用“前线坐标旗标 / 未完成标记”：一个开放角标或推进箭头用于标注学生项目、导师组、春季营、AI青年志；不做校徽或青春营地徽章。
- **色彩使用**：实验白 `#F7F9FA` 和银灰 `#D7DEE4` 更大面积，深墨蓝用于标题与机构锁定；青绿作为“前沿信号”；橙色可比方向一略活跃，用于招募召集、挑战任务、营员包，但单张海报仍控制 1 个焦点。
- **字体**：中文标题更有冲击：思源黑体 800，短句大字号；英文用 IBM Plex Sans Condensed 或紧排 Sans 做活动口号；Mono 只用于编号、坐标、任务标签，不让界面感压过人物。
- **海报系统**：纪实照片占 45–60%，人物 2–4 人在白板、代码审阅、实验设备、导师讨论现场；叠加坐标编号、任务标签、时间窗口和 1 个核心数据。适合 `集不凡·创奇迹 / Calling for Marvellers`、`破界、实战、超常规`、`开营即出征`。
- **应用**：招生与人才引进、营员包、录取通知、社交媒体封面、开放日、AI青年志、空间墙面、导师组介绍。
- **优势**：最有情感温度和传播力，能回应“学生为中心、以前沿为牵引”，避免学院显得只是一套系统或平台。
- **风险**：若照片选择不严谨，会滑向普通招生宣传或互联网公司招聘海报；必须坚持纪实科研现场，避免摆拍笑脸、握手、VR 头显、奖杯和鸡血口号。
