# Asset Generation Plan

## Rationale
创智学院是面向 AI 领军人才培养的“新型人才培养机构”，关键触点集中在官网招生、营地招生活动、TechFest / 成果发布、研究组子品牌、实验室空间导视与学术路演。资产组合因此以“可变网格 + 科研引擎 + 前沿信号”为核心，避免传统高校盾牌、书本、桂冠，优先覆盖数字传播、活动传播与空间识别。
