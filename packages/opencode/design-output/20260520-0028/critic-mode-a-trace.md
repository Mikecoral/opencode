## Rewrite Suggestions

### Design Keywords — proposed rewrite
- Modular intelligence grid / 模块化智识网格
- Central hub with open endpoints / 中枢节点与开放端点
- West Bund research infrastructure / 西岸科研基础设施感
- Bilingual research-engineering authority / 中英双语科研工程权威感
- Precise cyan signal on dark institutional substrate / 深色可信底盘上的精密青蓝信号
- Researcher-founder momentum / 研究者创业者动能
- From model to deployment / 从模型到部署
- Public mission, technical depth / 公共使命与技术深度

### Color Strategy — proposed rewrite
Use a disciplined four-layer palette. **Neutrals 85%:** Midnight Navy `#071A2D`, Cool White `#F6F9FC`, Graphite `#2B3440`, Mist Border `#D8E0EA`. **Primary accent 8%:** Intelligence Cyan `#00B8FF`, used only for active paths, node highlights, primary CTAs, and data signal moments. **Secondary accent 3%:** Data Violet `#6B5CFF`, reserved for research-category labels or motion transitions, never as a second equal brand color. **Semantic colors <3%:** Founder Orange/Open-source Green only inside charts or program taxonomies. Avoid cyan-violet hero gradients, glowing orbs, and decorative neon washes.

### Symbol & Mark — proposed rewrite
Prioritize an **SII modular lettermark** built from an 8×8 grid. Construct the “S” as a precise path moving through connected cells; construct the two “I” forms as stable vertical columns, suggesting institute pillars and model/data infrastructure. Include one central hub cell and 3–5 open endpoint cells to express connection without becoming a generic network icon. The mark must work in one color, at favicon size, in a square avatar crop, and beside the bilingual name “上海创智学院 / Shanghai Innovation Institute.” Explore “创/智” glyph-derived forms only as secondary alternates if they remain simpler and more ownable than the SII mark.

### Typography — proposed rewrite
Set a restrained bilingual technical-institutional type system: **Chinese:** Source Han Sans SC / Noto Sans SC, Semibold for titles, Regular for body. **English:** IBM Plex Sans, Semibold for titles and Regular for body, paired optically with the Chinese name at equal hierarchy. **Data/code layer:** IBM Plex Mono only for course codes, lab labels, model names, dataset IDs, and chart annotations. Use tight display tracking for large English headlines, slight tracking for all-caps labels, strong left alignment, and a limited scale suitable for dense admissions pages, white papers, PPT reports, and campus wayfinding.
