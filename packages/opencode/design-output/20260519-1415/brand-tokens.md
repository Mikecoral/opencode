# Brand Tokens: 创智学院（上海创智学院）

## Color Palette
| Role | Name | Hex | Usage |
|------|------|-----|-------|
| Primary | Deep Intelligence Navy | #071A2F | Logo, dark surfaces, research authority, structural grids |
| Accent | Signal Cyan | #00D4FF | CTAs, data nodes, frontier signal highlights, interactive emphasis |
| Surface | Lab White | #F6F8FB | Backgrounds, report pages, content cards, clean digital surfaces |
| Muted | Muted Graphite | #5C6673 | Secondary labels, metadata, captions, subdued interface text |

**Accent discipline:** one accent color only. Critic will flag a second accent as anti-slop violation.

## Typography
| Role | Style Description | Weight Range |
|------|-------------------|-------------|
| Display / Logo | rational narrow modern sans-serif with modular technical structure; compatible with bilingual SII / Chinese name usage | Bold / Black |
| Body | technical humanist / grotesk sans-serif, clear in research titles, web navigation, PPT body copy | Regular / Medium |
| Caption | restrained monospaced or monospaced-inspired sans-serif for code snippets, data labels, training logs, model metrics | Light / Regular |
