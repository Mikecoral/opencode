# Asset Generation Plan

## Rationale
上海创智学院的核心差异不是传统学院形象，而是“面向 AI 前沿无人区的项目制创新学院”：以算力、导师组、产业科研网络和学生自主项目为驱动。Section 11 的最高优先级集中在招生营、科研进展、青年教师招聘、学术讲坛这类高频数字传播触点，因此本轮应建立一套“前沿信号 + 高密度信息模板”的传播系统，而不是做校园、宣传册或周边的行业默认包。

## Visual Direction
- Selected: research-signal
- Why: Brief 明确要求转向“智能系统、开放网络、前沿信号、实验场”，Section 5 将算力节点、模型层、流动数据、开源代码块、任务卡、checkpoint、导师网络列为主要视觉 DNA。
- What this prevents: 避免传统教育机构的盾牌、书本、橄榄枝、校园风景、招生宣传册式叙事，也避免过度赛博朋克发光导致学术可信度下降。

## Deliverable Strategy
- Selected: digital-system
- Why: Section 11 的 Top priority 触点大多是官网、社交卡片、招聘 banner、讲坛海报/PPT、招生营数字招募信息；这些需要统一的数字版式、标题层级、数据标签和信号图形语言。

| 青年教师/导师招聘视觉 | Top priority | Section 11: 官网首页突出“全球引进青年教师 / Calling for Marvellers”，人事人才是主导航栏目。 | Include as recruitment banner |
| 学术报告/创智讲坛海报与PPT模板 | Top priority | Section 11: 创智讲坛、导师系列和学生系列支撑学术活动文化生态。 | Include as lecture/event poster template |

## Self-Check
- Does this plan avoid the predictable industry bundle? yes — it avoids campus views, brochures, generic admissions collateral, shields, books, and school-color sampler assets; the system is built from signal, compute, research and mission-training evidence.
- Are all non-logo assets tied to Top priority touchpoints or the selected strategy? yes — research card, summer camp card, faculty banner, forum poster, and report/PPT cover all map to Section 11 Top priority digital communication needs.
- Did you avoid defaulting to color-palette/campus/admissions/brochure/merchandise? yes — no standalone color-palette, campus, brochure, or merchandise asset is included; the admissions-related need is reframed as a mission-style summer camp card because 招生营 is explicitly Top priority.
- Does the set feel like one coherent system rather than unrelated samples? yes — all assets use one research-signal visual language: Deep Intelligence Navy, Signal Cyan, modular grids, compute nodes, task checkpoints, model layers, and restrained technical typography.
