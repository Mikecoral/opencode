# 视觉方向选项

## 方向一：RUNSTACK OS / 运行栈操作系统
- 核心主张：把上海创智学院呈现为一个正在运行的“AI科研操作系统”，每个招生、科研、导师、项目触点都是栈内可调度的任务模块。
- 与简报的契合：最直接承接“全栈科研系统、任务流、节点拓扑、堆栈卡片、科研驾驶舱”；适合“创奇·智能新引擎”这类复杂成果发布，也能服务官网科研新闻和博士遴选流程说明。
- 潜在风险：若界面元素过密，会显得像企业SaaS后台或黑客大屏；若过度使用蓝紫青，会落入泛AI网格套路。
- 调色板取向：深色优先。深空石墨 `#101217` 占主背景；智能蓝 `#225CFF` 用于主行动、关键节点、链接；能动紫 `#7A4DFF` 只用于模型训练/跨学科模块；实验青 `#00C2B8` 用于数据闭环和生命科学相关状态；突破橙 `#FF7A1A` 限定为“发布/招募/挑战”瞬时高光。冷白 `#F5F7FA` 用于长文档和反白文字区域。
- 字体取向：中文为理性无衬线中高字重标题 + 高可读正文；英文采用几何与人文混合无衬线；辅助引入等宽字体表现版本号、任务编号、运行状态、时间戳、数据标签。标题可紧凑有力，正文不能用过细字重。
- 版式/构图：12列或更细的技术网格；页面像“堆栈视图”：顶层为SII权威标识和主标题，中层为任务卡/导师卡/成果卡，底层为细线拓扑和状态条。构图节奏强调左对齐、清晰层级、模块间可插拔；动效可从“排队—运行—验证—发布”四态展开。
- 最适合的资产类型：科研成果发布会主视觉、科研全栈解释图、官网科研栏目组件、招生遴选流程页、报告PPT模板、视频片头中的任务流动效。
- 负向引导：不要做霓虹粒子、宇宙隧道、发光脑、无意义代码雨；不要把所有信息放进大屏仪表盘；不要让青色网格铺满每张海报；不要使用3D金属芯片或赛博城市背景。

## 方向二：OPEN LAB ATLAS / 开放实验室图谱
- 核心主张：以浅色、编辑化、图谱化语言呈现“顶尖青年研究者进入开放实验室共同探索”的学院气质。
- 与简报的契合：回应“能动而克制、青年主战位、导师共创、开放共享空间”；比方向一更适合招生营、学术报告、招聘和对外传播，能避免过冷的纯技术界面。
- 潜在风险：若处理不够锐利，可能回到普通高校宣传册；若摄影选择过于校园生活化，会削弱“AI领军人才 + 有组织科研平台”的前沿感。
- 调色板取向：浅色优先。冷白 `#F5F7FA` 和纸感白作为主背景；深空石墨用于标题和信息骨架；智能蓝作为唯一主识别色；突破橙用于“申请、截止、挑战题、成果发布”短促提示；实验青只用于科学图谱或实验数据，不与橙同屏大面积竞争。整体明度更高、饱和度更克制。
- 字体取向：中文采用开阔、现代、人文理性的无衬线，标题不必过粗，重在清晰和空气感；英文标题可用Semibold建立国际研究机构气质；等宽体只作为脚注式标签，不主导版面。
- 版式/构图：编辑式大留白 + 学术图谱。可用大标题、短引文、人物/空间/实验对象照片、轻量数据注释构成“研究档案页”；构图节奏像期刊目录和展览墙：一张主图、一组节点注释、一个清晰行动入口。图形不是背景纹样，而是解释研究关系的线框、编号、坐标、索引。
- 最适合的资产类型：招生营主视觉与长图、青年教师招聘、学术讲坛海报、官网学院概况/人物访谈、纸质邀请函、开放日导览、社媒图文。
- 负向引导：不要使用学士帽、书本、麦穗、盾牌、校门航拍等传统高校符号；不要把学生照片做成热血拼贴；不要做浅蓝渐变云、抽象光束或口号大字报；不要让版面变成普通政府/高校简报。

## 方向三：CO-CREATE GLYPHS / 共创生成字形
- 核心主张：建立一个可生成的SII符号族，用同一底层栅格表达学生、导师、产业伙伴、科研平台和活动营的多中心共创。
- 与简报的契合：呼应“导师组与共创生态、轻量课程与灵活修读、模块化可重组”；借鉴MIT Media Lab式“固定母体 + 多样分支”，但转译为SII三层栈、创/智抽象笔画、课程/项目/导师节点的组合系统。
- 潜在风险：生成符号若太复杂会像装饰花纹，中文名称识别会被削弱；若规则不严，活动越多视觉越散。
- 调色板取向：均衡但高纪律。主系统仍以黑白灰为骨架；每类资产只允许一个主强调色：招生营用智能蓝，科研发布用能动紫，挑战/招募用突破橙，数据/实验专题用实验青。允许在海报中使用大面积纯色块，但同一张资产不超过两种高饱和色。
- 字体取向：主标题使用更有结构感的无衬线Bold/Semibold，形成与生成glyph相称的“构造感”；正文保持理性可读；英文缩写、项目编号、营期编号可使用等宽或窄体无衬线，形成系列编码。
- 版式/构图：以底层栅格生成符号、边框、分隔线和动态图形。版面可更具活动感：大号SII/创智glyph占据一侧，信息块插入栅格空位；海报、证件、营服、PPT封面可通过不同glyph变体形成系列。构图节奏比方向一更图形化，比方向二更年轻和高能。
- 最适合的资产类型：四季训练营视觉、学术活动系列海报、项目组/导师组子品牌、空间导视编号、徽章/贴纸、成果发布分论坛、社媒动态模板。
- 负向引导：不要直接复制MIT Media Lab的7×7像素标；不要为每个活动随意造一个新logo；不要让glyph替代官方中英文组合标识；不要使用过度潮流的酸性色、故障字、贴纸堆叠，以免降低顶尖科研机构可信度。

## 推荐方向
- 推荐方向：优先探索“RUNSTACK OS / 运行栈操作系统”，并在招生与招聘触点中吸收“OPEN LAB ATLAS”的浅色编辑化表达。
- 为何优先探索此方向：它最能体现简报中最独特的差异化——“AI领军人才培养 + 有组织科研平台 + 产学研创生态”不是普通学院，而是可运行、可迭代的科研系统；同时可为成果发布、官网组件、招生流程、PPT模板建立统一语法。
- 针对本简报应规避的方向：规避传统校徽/校史/校园摄影主导方向；规避单一深色科技蓝网格方向；规避过度消费科技极简导致组织复杂性消失的方向；规避为每个活动独立换皮的彩虹活动品牌。
