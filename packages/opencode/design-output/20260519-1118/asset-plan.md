# 资产生成计划

## 决策依据
本次以用户认可的方向一“RUNSTACK OS / 运行栈操作系统”为起点，把上海创智学院呈现为“正在运行的AI科研操作系统”，而不是传统高校院徽或校园宣传。简报第2章明确指出学院差异化是“AI领军人才培养 + 有组织科研平台 + 产学研创生态”，第5章又将“全栈科研系统、任务流、节点拓扑、堆栈卡片、科研驾驶舱”列为核心视觉DNA，因此本轮优先建立一套可用于官网、招生遴选、科研发布与学术活动的数字传播组件。

## 视觉方向
- 所选方向：`research-signal`（RUNSTACK OS / 运行栈操作系统）
- 原因：direction-options.md 推荐优先探索“RUNSTACK OS”，其最直接承接简报中的“全栈科研系统、任务流、节点拓扑、堆栈卡片、科研驾驶舱”；同时能够服务第11章列为首要的科研成果发布、官网新闻组件、博士遴选流程说明与学术活动模板。
- 规避了什么：规避“学校 = 校徽 + 校园摄影 + 招生折页”的默认包；也规避泛AI霓虹粒子、宇宙隧道、发光脑、代码雨和过密黑客大屏。

## 交付策略
- 所选策略：`digital-system`
- 原因：第11章首要触点中，官网与科研新闻、招生遴选信息、成果发布传播、学术日历均高度依赖线上入口与可复用数字模板；本轮将“主视觉/海报/发布会”统一转译为数字传播系统，而不是拆成独立活动视觉或印刷物料。

## 触点优先级

| 官网与科研新闻版式组件 | 首要 | 第11章：官网是学院官方入口，承载学院概况、科研进展、招生、招聘与联系方式。 | 包含：作为本轮数字系统的核心触点。 |

| 文创周边 | 本轮不做 | 第11章：对顶尖AI人才培养的核心沟通价值较低。 | 排除：会使系统滑向社区周边包。 |
| 传统招生折页大礼包 | 本轮不做 | 第11章：目标人群主要通过官网、遴选系统、活动营与科研内容了解学院。 | 排除：与线上遴选和数字传播优先级不匹配。 |

## 自检
- 本计划是否规避了可预测的行业默认包？是。未采用“院徽、校园航拍、招生折页、学生合影、校史典礼感”的默认学校包，而是从RUNSTACK OS的科研运行语法出发。
- 所有非Logo资产是否都关联到首要触点或所选策略？是。六项资产均服务官网、招生遴选、科研发布或学术活动这四类首要数字触点。
- 是否避免了默认添加 color-palette/campus/admissions/brochure/merchandise？是。未生成调色板板、校园宣传图、传统招生折页或周边；招生资产被限定为数字流程与通知模板。
- 整套资产是否像一个连贯系统而非互不相关的样品？是。所有资产共享“深空石墨 + 智能蓝 + 冷白/线框灰”、堆栈卡片、任务流、状态条、左对齐技术网格与等宽数据标签逻辑。
