## Cultural & Visual DNA — Derivation

- Searched官网概况 → found “以学生为中心、以前沿为牵引”“AI领军人才”“世界人工智能创新高地” → therefore chose “青年科学家创客共同体”“前沿信号”“改变世界的成果” as strategic language.
- Fetched CCTV article → found 五大科研阵地（认知、情境、具身、科学、AI基础设施） → therefore chose a five-subsystem visual architecture with grid/glyph expansion.
- Fetched Pentagram MIT Media Lab → found 7×7 grid extended to 23 research group glyphs → therefore recommended SII intelligent grid and research-direction glyphs.
- Fetched The Paper → found 北杨人工智能小镇、玻璃幕墙、新建商务楼、“一切都是新的” → therefore chose glass, grid, light, urban interface and modular architecture as visual motifs.
- Fetched SII homepage and 视觉创智 → found existing logo assets, bilingual navigation, image/video/event content → therefore recommended system upgrade rather than total replacement.
- Fetched Shangguan → found “科学家创客社区”、学生 PI、课程快速迭代 → therefore chose open-source contribution graph, project cards, maker badges and agile event templates.
