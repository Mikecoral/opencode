# Asset Generation Plan

## Rationale
This run should express Shanghai Innovation Institute as an AI frontier research-and-maker community, not as a conventional college brand. The brief emphasizes a generative grid, frontier signal monitoring, project-based research, website/research pages, TechFest-style recruitment touchpoints, and talent attraction; therefore the system should prioritize digital research communication and scalable identity signals.

## Visual Direction
- Selected: research-signal
- Why: Section 7 names “AI 无人区,” “开源基础设施,” “可生成网格,” and “滨江夜航”; Section 10 calls for an SII generative grid mark and three-node progress path from impossible to public benefit.
- What this prevents: Avoids the generic education bundle of campus photography, admissions brochures, shield crests, and broad student-life imagery.

## Deliverable Strategy
- Selected: digital-system
- Why: Section 11 ranks the official homepage/research results visual system as Top priority, with project subbrand systems, event materials, and recruitment visuals all needing a coherent digital-first language.

## Self-Check
- Does this plan avoid the predictable industry bundle? yes — it avoids campus scenery, crest badges, admissions brochures, and merchandise, focusing instead on research signals, digital systems, and generative identity logic.
- Are all non-logo assets tied to Top priority touchpoints or the selected strategy? yes — each non-logo asset maps to website/research pages, event recruitment, project subbrands, or mentor recruitment.
- Did you avoid defaulting to color-palette/campus/admissions/brochure/merchandise? yes — color is tokenized only, campus/signage is deferred, admissions is reframed as a TechFest/open-day key visual, brochure and merchandise are rejected.
- Does the set feel like one coherent system rather than unrelated samples? yes — all six assets use the same research-signal direction: dark research base, electric cyan signal paths, generative grids, modular project identifiers, and digital-first layouts.
