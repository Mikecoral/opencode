# 视觉方向选项

## 方向一：GRID-ENGINE / 全栈算力引擎
- 核心主张：把创智学院呈现为一套“可运行、可扩展、可版本化”的 AI 科研基础设施。
- 与简报的契合：最贴合“算力集群、科研驾驶舱、全栈引擎、模块化 monogram、项目子符号”的视觉 DNA；适合招生营、科研成果发布、平台产品和官网科研项目卡片。
- 潜在风险：容易滑向通用深色科技/青色网格；若图形规则不够独特，会像云计算公司而不像新型学院。
- 调色板取向：深色优先。深空黑/算力墨蓝为 60–70%，冷灰与白为信息层，创智电蓝为主操作色，引擎荧青只做 5–10% 的链路/状态高亮，创奇红只用于发布、招募与关键警示。
- 字体取向：标题使用压缩或几何黑体，短促有工程决断力；正文用高可读人文无衬线；数据、日期、机考、算力指标使用等宽字体，形成“代码/任务队列”层。
- 版式/构图：模块化网格、项目卡片、节点链路、版本号、时间戳、状态标签；主视觉可由“创/智/SII”抽象成底层网格，再派生 AI Infra、数据工厂、科研驾驶舱、NEXChem、NEXMed、安全矩阵等子 glyph。
- 最适合的资产类型：主标识延展、项目子符号、科研成果发布屏、官网项目卡、报告模板、平台 UI、AI Infra 营视觉系统。
- 负向引导：不要做满屏赛博线框、随机粒子、蓝紫大渐变、无意义 HUD；不要直接复刻 MIT Media Lab 7×7 方块；不要让荧青承担正文阅读。

## 方向二：GLASS-CAMPUS / 西岸玻璃实验室
- 核心主张：把创智学院塑造成“城市中的开放科研实验室”：前沿、透明、可信，并有人在其中工作。
- 与简报的契合：回应徐汇西岸、北杨人工智能小镇、玻璃幕墙、灯火通明的新空间气质，也能平衡“国家战略任务”与“青年创客共同体”的张力。
- 潜在风险：若摄影和材质控制不佳，会变成地产宣传或普通高校形象片；需要真实空间、人物、实验现场资产支撑。
- 调色板取向：均衡偏浅。雾白/浅灰/银灰作为大面积背景，墨蓝与黑用于标题和夜间场景，电蓝作为链接和导视，红色只做少量使命提示；可加入玻璃反射的低饱和蓝灰，不使用高饱和霓虹铺底。
- 字体取向：标题可用稳重几何无衬线或带轻微人文感的黑体；长文与招生说明优先高可读无衬线；重要致辞/成果封面可少量引入现代衬线或宋体风格，增强学术可信。
- 版式/构图：大留白、宽幅影像、玻璃反射裁切、人物与设备的真实比例；信息区像建筑导视和展陈面板，使用清晰栏栅、编号和项目地图，不强调复杂 HUD。
- 最适合的资产类型：官网首页、人才招募页、导师/学生故事、空间导视、楼宇欢迎屏、成果展板、媒体发布材料。
- 负向引导：不要用地产鸟瞰、空泛城市天际线、过度磨皮人物照；不要把学院拍成传统校园宣传；不要堆砌玻璃反光导致文字不可读。

## 方向三：MAKER-PROTOCOL / 青年创客协议
- 核心主张：把品牌做成“招募共创者的开放协议”：快速、直接、有实验痕迹，像 48 小时课题实训的作战台。
- 与简报的契合：强化“破界、实战、超常规、学生主战位、创客社区”；特别适合博士遴选、夏令营/春季营、黑客松式课题、青年教师招募和社交媒体海报。
- 潜在风险：过于粗粝会削弱政府/高校/企业合作场景中的权威感；需要与主品牌系统建立清晰边界，作为活动/招募子语气更稳妥。
- 调色板取向：浅色优先。白/浅灰/纸张米白为底，黑色大标题，创奇红作为行动召唤，电蓝用于链接和流程节点，可少量加入警示黄或荧青作为贴纸/标签，但不形成彩虹混杂。
- 字体取向：超大压缩黑体或重磅黑体标题，配等宽标签、编号、代码块；正文保持简洁无衬线。中文标语可采用紧凑字距，制造“招募令/任务书”的冲击。
- 版式/构图：不对称分栏、贴纸标签、任务清单、流程图、机考界面截面、手写批注感；视觉节奏像 README、Issue board、实验日志和战术海报的混合。
- 最适合的资产类型：招生营 KV、机考/面试流程海报、48 小时课题实训物料、人才招募长图、社媒短讯、开放项目 README 封面。
- 负向引导：不要做街头涂鸦、二次元校园社团感或廉价黑黄警示风；不要牺牲信息准确性；不要把所有正式报告也做成“作战海报”。

## 推荐方向
- 推荐方向：优先探索 **GRID-ENGINE / 全栈算力引擎**，并为招募/营地触点预留 **MAKER-PROTOCOL** 子语气。
- 为何优先探索此方向：它最能承接简报中的核心差异——AI Infra、科研驾驶舱、数据工厂、项目制与平台化成果；同时可从现有“竖向图形 + 中英文字标”结构发展为主标识、子项目 glyph、官网卡片和发布会图谱，资产复用效率最高。
- 针对本简报应规避的方向：传统学院盾牌/书本/橄榄枝；纯深色赛博蓝青网格；地产化玻璃楼宣传；OpenAI 式过度中性极简；无规则 AI 生成抽象图。
