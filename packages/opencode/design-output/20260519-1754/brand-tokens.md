# Brand Tokens: 上海创智学院

## Color Palette
| Role | Name | Hex | Usage |
|------|------|-----|-------|
| Primary | Deep Compute Navy | #07111F | Logo, dark digital backgrounds, research authority |
| Accent | Signal Cyan | #00D1FF | Frontline signal, interaction highlights, AI infra/data-flow emphasis |
| Surface | Surface Fog | #F4F7FA | Website surfaces, long-form content backgrounds, light layouts |
| Muted | Graphite | #1E2530 | Body text, secondary UI labels, dense information panels |

**Accent discipline:** one accent color only. Marveller Violet and Warm Spark are acknowledged from the brief but intentionally withheld from this run to preserve a single research-signal accent system.

## Typography
| Role | Style Description | Weight Range |
|------|-------------------|-------------|
| Display / Logo | rational, narrow, engineering-minded humanist sans-serif for Chinese; restrained neo-grotesk for English, high-density research-poster tone | Bold / Black |
| Body | highly legible humanist sans-serif suitable for long research summaries and bilingual institutional text | Regular / Medium |
| Caption | compact sans-serif with optional monospaced numeric/code styling for project IDs, dates, metrics, GitHub links, and Demo labels | Light / Regular |
