# Asset Generation Plan V2

## Rationale
The approved brief explicitly defines the design thesis as **“Frontier Signal Grid / 前沿信号网格”** and asks the identity to look like “一个正在运行的科研操作系统，而不是一张招生海报.” This run should therefore prioritize a digital-first identity system: a compact SII grid mark, an extensible signal-grid graphic language, and high-priority communication modules for research, web, TechFest/open day, and doctoral selection.

The plan intentionally avoids a generic school bundle. It does not lead with campus scenery, admissions smiling-student posters, brochures, crests, blue-gold institutional symbolism, or merchandise; the visual answer must show **AI research signals, project tags, coordinates, nodes, slices, and structured bilingual information.**

## Visual Direction
- Selected: `research-signal`
- Why: Section 3 defines SII as “信号站 / 网格 / 实验场 / 上海节点,” and Section 4 recommends Direction A: “用 SII 字母或‘创智’笔画建立基础网格，衍生节点、扫描线、方向场和项目信号.” Section 8 further specifies Grid, Node, Signal line, Data slice, and Project badge as the graphic system.
- What this prevents: This prevents defaulting to a traditional education identity (`institutional-minimal` with crest/campus) or a generic AI company look with brains, chips, blue-purple gradients, robot mascots, or cyberpunk glow.

## Deliverable Strategy
- Selected: `digital-system`
- Why: Section 13 recommends a first-round “数字优先品牌系统” with SII Grid Mark, auxiliary grid rules, website hero, research cards, TechFest/open day KV, doctoral selection timeline, and research update template. Section 10 also ranks website hero, research project cards, TechFest/open day KV, and doctoral selection timeline as Top priority.
- Why not `identity-core`: Identity is essential, but the brief’s problem is not only “make a logo”; it is to prove the brand can continuously explain research projects, talent calls, and public-facing innovation activity.

## System Coherence Notes
- Core forms: all assets must derive from the same 7×7 or 8×8 computational grid, not unrelated tech abstractions.
- Core graphic vocabulary: node, signal line, data slice, coordinate frame, and project badge.
- Core color discipline: Deep Compute Navy `#07111F`, Surface Fog `#F4F7FA`, Graphite `#1E2530`, Signal Cyan `#00D1FF`; Marveller Violet `#7C3DFF` and Warm Spark `#FFB000` only for limited event/status uses, never as a generic gradient.
- Core typography: rational narrow humanist sans for Chinese, restrained neo-grotesk/grotesk for English, mono or quasi-mono for dates, project IDs, version numbers, demo states, and metadata.
- Core tone: frontier research operating system + maker proof-of-work, not school prestige, not AI spectacle, not government exhibition board.
