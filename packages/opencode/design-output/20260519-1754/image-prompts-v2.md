# Cross-Asset Consistency Checklist

- Use the same **Frontier Signal Grid** vocabulary throughout: 8x8 computational grid, nodes, signal line, data slice, coordinate/panel logic, project badge.
- Keep the core palette consistent: Deep Compute Navy `#07111F`, Surface Fog `#F4F7FA`, Graphite `#1E2530`, Signal Cyan `#00D1FF` as the only recurring accent.
- Use Marveller Violet `#7C3DFF` only in `techfest-key-visual`, and only once as a controlled event/status point.
- Maintain restrained bilingual typography: rational narrow humanist sans for Chinese, controlled grotesk for English, monospaced labels for metadata.
- Avoid all forbidden shortcuts across the set: no crest, no generic AI brain/chip/robot, no cyberpunk, no campus scenery, no generic admissions brochure, no blue-purple gradient.
- Keep every asset focused on one dominant subject; do not combine logo, palette, typography specimen, and mockup into a single image.
