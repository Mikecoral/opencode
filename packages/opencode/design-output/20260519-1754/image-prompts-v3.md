Labels such as `TechFest / Future Intelligence`, `Doctoral Selection Pipeline`, `YYYY`, month labels, and project/status tags are visual placeholders for brand-system exploration, not new factual claims about official events, dates, or programs.

System theme: **Frontier Signal Grid / 前沿信号网格** — a digital-first identity system for 上海创智学院 / Shanghai Innovation Institute that should feel like a running research operating system, not a traditional school package or generic AI company visual.

Core visual constants:
- Grid: 7x7 or 8x8 computational grid.
- Motifs: nodes, signal line, coordinate frame, data slice, project badge.
- Palette: Deep Compute Navy `#07111F`, Surface Fog `#F4F7FA`, Graphite `#1E2530`, Signal Cyan `#00D1FF`.
- Limited accents: Marveller Violet `#7C3DFF` only for event/status energy; Warm Spark `#FFB000` only if a tiny breakthrough/status dot is needed.
- Typography direction: rational narrow humanist sans for Chinese, restrained grotesk or neo-grotesk for English, mono or quasi-mono for metadata.

# Cross-Asset Consistency Checklist

- Every asset should visibly belong to the same **Frontier Signal Grid** system: 7x7/8x8 grid, nodes, signal line, data slice, coordinate/panel logic, and project badge.
- The logo assets must allow words; `logo-primary` is now a symbol-first identity sheet, and `bilingual-lockup` is the practical name-lockup system.
- Palette must stay disciplined: Deep Compute Navy `#07111F`, Surface Fog `#F4F7FA`, Graphite `#1E2530`, Signal Cyan `#00D1FF`.
- Marveller Violet `#7C3DFF` appears only in `techfest-key-visual`; Warm Spark `#FFB000` is not used in v3 prompts.
- Text must be short and exact. Do not ask the image model to typeset long paragraphs.
- Do not invent institutional facts: no fake rankings, exact dates, partner names, faculty names, official event details, publication claims, or metrics.
- Avoid all forbidden visual shortcuts: school crest, generic AI brain/chip/robot, cyberpunk, campus scenery, blue-purple gradient, government exhibition board, and generic admissions brochure.
