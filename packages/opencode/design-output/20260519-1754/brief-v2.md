# 上海创智学院 / Shanghai Innovation Institute 品牌形象设计简报 V2

**Subject Type:** organization

## 0. 设计任务一句话

为上海创智学院做一套不像传统高校、也不像泛泛 AI 公司，而像“面向未来的 AI 科学家创客共同体”的品牌身份系统：可信、前沿、开放、能把科研项目与人才召集持续讲清楚。

**3 秒识别目标：**如果一个人只看 3 秒，应立即理解——**这是一所位于上海、以 AI 前沿研究和项目制培养为核心的新型创新学院；它不只是招生机构，而是把顶尖人才、科研、产业转化和创客文化连接在一起的实验场。**

---

## 1. 不是重写介绍，而是重定义感知

### 已有事实 grounding
- 创智学院官方定位为“新型人才培养机构”，聚焦 AI 领军人才培养与世界人工智能创新高地建设 [source: https://www.sii.edu.cn/xygk/list.htm]。
- 官网内容同时覆盖招生培养、科研创新、人事人才、视觉创智等触点 [source: https://www.sii.edu.cn/main.htm]。
- 公开传播中出现“科学家创客社区”“项目制”“破界选才”等关键信号 [source: https://export.shobserver.com/baijiahao/html/982544.html]。
- 科研内容覆盖 MOSS、机器人、多模态推理、AI for Science 等高技术密度方向 [source: https://www.sii.edu.cn/8/list.htm]。

### 当前品牌问题
创智学院的真实气质很强，但如果视觉处理不准，容易落入三种误区：
1. **传统高校化**：校徽、蓝金、楼宇、口号，显得稳但不新。
2. **通用 AI 化**：脑图、芯片、蓝紫渐变、抽象光线，显得“像任何一家 AI 公司”。
3. **政府项目化**：宏大叙事过多，削弱年轻科学家、创客和项目现场感。

### 期望感知转移
| From 现在容易被误读为 | To 新身份要建立的认知 |
|---|---|
| 一所新成立的学院 | 一个快速迭代的 AI 人才与科研实验场 |
| 招生单位 | 召集 Marvellers、导师、企业和项目的开放网络 |
| 学术机构 | 有学术可信度、也能把 idea 做成 demo / product 的创客共同体 |
| 上海又一个 AI 平台 | 上海西岸语境中的前沿信号站与项目孵化节点 |

## 2. 品牌战略核心

### 品牌主张
**Create intelligence. Prove it in the real world.**  
中文可转译为：**创智：让前沿智能被创造、被验证、被转化。**

### 设计命题
**用“信号网格”取代“校徽图腾”。**  
传统学院通常用封闭徽章表达权威；创智学院更适合用一个可扩展、可生成、可承载项目的视觉系统表达：前沿信号、算力基础、跨学科连接、项目制实战。

### 品牌人格
- **前沿但不浮夸**：像实验室和研究海报，不像科技发布会背景板。
- **高密度但有秩序**：允许信息复杂，但必须通过网格、标签、编号和层级被清晰组织。
- **开放但有门槛**：不是大众教育品牌，而是召集少数真正愿意做难题的人。
- **年轻但不娱乐化**：可以有贴纸、项目墙、Demo Day 语言，但不可变成潮牌。

## 3. 视觉 thesis：Frontier Signal Grid

推荐总方向：**Frontier Signal Grid / 前沿信号网格**

视觉不以“AI 大脑”作为中心，而以**信号、节点、坐标、切片、项目标签**构成系统。它表达创智学院的四层身份：
1. **SII 是信号站**：识别全球 AI 前沿方向。
2. **SII 是网格**：连接学生、导师、产业、算力、项目。
3. **SII 是实验场**：项目被快速立项、验证、展示。
4. **SII 是上海节点**：冷静、城市化、面向未来，而不是传统校园叙事。

一句视觉判断标准：**看起来像一个正在运行的科研操作系统，而不是一张招生海报。**

## 4. 三个创意方向

### Direction A — Frontier Signal Grid / 前沿信号网格（推荐）
**概念：**用 SII 字母或“创智”笔画建立基础网格，衍生节点、扫描线、方向场和项目信号。主标简洁，辅助图形可变。

**视觉语言：**深色计算背景、青色信号、细线网格、坐标标签、动态扫描、研究项目卡片。

**适合触点：**官网 hero、科研成果卡、TechFest KV、招生遴选时间线、社交更新模板。

**优点：**
- 最贴合 AI 前沿、算力、项目制和科研传播。
- 系统性强，可持续生成研究方向、活动和项目子图形。
- 避免高校徽章套路，也避免通用 AI 脑图。

**风险：**
- 如果控制不好，会显得过冷、过工程，需要加入“创客社区”的人味：贴纸标签、手写式项目批注、Demo 状态章。

### Direction B — Maker Lab Commons / 科学家创客公社
**概念：**把学院表现为开放工坊：项目墙、白板草图、贴纸、工牌、模块化 badge，强调“把点子变产品”。

**视觉语言：**高对比黑白、荧光点色、贴纸图标、手绘箭头、项目编号、工坊材料感。

**优点：**
- 年轻、有社群感，非常适合开放日、训练营、黑客松和周边。
- 能强化“新型学校”与传统高校的差异。

**风险：**
- 容易削弱顶尖科研机构的公信力。
- 如果先做这个方向，可能像 maker space 或创业营，而不是国家级 AI 顶尖人才培养平台。

### Direction C — Shanghai AI Academy / 上海智能学院派
**概念：**强调上海西岸、国际化学院、理性学术秩序。视觉更克制，更接近高端研究机构。

**视觉语言：**留白、建筑线、滨水水平线、精细排版、低饱和蓝灰、双语学术版式。

**优点：**
- 稳重、国际化，适合政府、合作高校、企业和媒体场景。
- 不容易出错，长期耐看。

**风险：**
- 差异化不足，容易回到“传统学院 + 科技蓝”。
- 对年轻 AI 人才的召集力不如 A 和 B。

### 推荐
采用 **Direction A — Frontier Signal Grid** 作为主系统；吸收 Direction B 的局部社区语言作为辅助层；避免 Direction C 成为主视觉，只保留它的克制排版和国际化留白。

## 5. Logo / Mark 路线

### 路线 1：SII Grid Mark（首选）
以 SII 三个字母为骨架，放入 7×7 或 8×8 网格。不要直接画字母，而是通过“节点亮起 / 线段连接 / 切片缺口”让 SII 被识别出来。

**关键词：**generated, modular, signal, compact, institutional but alive。  
**要求：**
- 16px favicon 下仍可识别为独特符号。
- 中文“上海创智学院”和英文“Shanghai Innovation Institute”可分别锁定，也可双语组合。
- 主标必须静态成立；动态版本可有扫描线或节点点亮。

### 路线 2：“创智”抽象笔画标
从“创”的立刀旁与“智”的日/知结构中提炼垂直切片与信息窗口，形成中文根性的抽象符号。

**优点：**更有中文识别。  
**风险：**抽象难度高，处理不好会像书法科技风或地方文创。

### 路线 3：Frontier Signal Beacon
以雷达、信号塔、坐标原点为隐喻，形成一个向外扩散的标志。

**优点：**非常直观地表达“前沿信号”。  
**风险：**容易像通信公司、实验室平台或科幻活动标。

### 推荐 logo 组合
**主标：SII Grid Mark**  
**辅助图形：Signal Beacon / Research Glyphs**  
即：主标克制、可注册、可长期使用；辅助系统负责变化、活动感和研究方向表达。

## 6. 色彩策略

### 主色
- **Deep Compute Navy `#07111F`**：主背景、品牌深色基底。表达夜间实验室、算力、研究可信度。
- **Surface Fog `#F4F7FA`**：长文、官网、正式文件和浅色背景。
- **Graphite `#1E2530`**：正文、信息块、标签文字。

### 信号色
- **Signal Cyan `#00D1FF`**：唯一主强调色，用于信号、节点、CTA、活动关键词、数据高亮。

### 限量辅助色
- **Marveller Violet `#7C3DFF`**：只用于人才召集、TechFest、训练营等更具探索感的场景。
- **Warm Spark `#FFB000`**：只作为“突破 / Demo / 发布”状态点，不大面积铺。

### 色彩规则
1. 80% 深色/浅色中性基底 + 15% 青色信号 + 5% 特殊状态色。
2. 禁止大面积蓝紫渐变作为默认 AI 感。
3. 亮色必须绑定信息功能：节点、进度、坐标、状态、CTA；不做装饰性发光。

## 7. 字体与排版方向

### 中文
理性、窄幅、工程感的人文无衬线。标题可以紧字距、高字重，像研究会议海报；正文必须适合长篇科研介绍和招生说明。

### 英文
克制 neo-grotesk / grotesk，避免过度未来感。英文用于 Shanghai Innovation Institute、project names、paper-like captions、event metadata。

### 数字 / 代码 / 标签
引入等宽或准等宽风格，用于：项目编号、日期、算力指标、版本号、GitHub、Demo 状态、方向代码。

### 排版规则
- 标题像“研究命题”，不要像广告 slogan。
- 信息层级采用：Title / Signal line / Metadata / Evidence block / CTA。
- 允许中英混排，但必须网格对齐；英文不是装饰，应承担导航和国际化功能。

## 8. 图形系统规则

### 基础图形
1. **Grid**：7×7 或 8×8 基础网格，承载 SII、研究方向、项目状态。
2. **Node**：节点表示学生、导师、项目、算力、企业合作点。
3. **Signal line**：扫描线、轨迹线、方向线，表示前沿监测和快速迭代。
4. **Data slice**：半透明切片、坐标框、窗口，表示多模态、张量、跨学科。
5. **Project badge**：小尺寸标签，用于项目名、Demo、Open Call、Research Update。

### 生成规则
- 每个研究方向可生成一个 glyph，但所有 glyph 必须来自同一网格逻辑。
- 线条粗细控制在 1–3 档，不做复杂霓虹线团。
- 图形密度随触点变化：官网 hero 可高密度；正式文件低密度；社交卡片中密度。
- 动态版本只允许三种动作：节点点亮、扫描经过、网格重组。

---

## 9. 图像、材质与空间语言

### 摄影方向
不拍“空旷校园风景”。优先拍：
- 深夜实验室灯光、屏幕、白板、项目桌面。
- 真实导师学生讨论、Demo 调试、设备局部。
- 上海西岸 / 北杨 AI 小镇的城市更新质感：玻璃、金属、夜色、滨水反光。

### 材质语言
- 深色哑光底 + 局部青色发光。
- 玻璃叠层、半透明面板、金属细边框。
- 纸质物料可用低反光银墨或局部 UV 表达“信号层”，但不做奢华烫金。

### 插画 / 3D
谨慎使用。若使用，必须是抽象系统图、拓扑、机器人局部、数据切片，不使用卡通机器人、发光大脑、宇宙星云。

## 10. 应用优先级

| Touchpoint | Priority | 设计目标 |
|---|---|---|
| 主标与双语 lockup | Top | 建立长期身份锚点，解决“这是谁”的第一识别。 |
| 官网 hero / 栏目视觉系统 | Top | 官网承担招生、科研、人事与传播入口，需要统一界面气质。 |
| 科研项目展示卡 | Top | 把复杂科研成果转成可读、可信、可分享的视觉模块。 |
| TechFest / 开放日 / 成果发布 KV | Top | 用事件快速建立公众对“新型学校”的感知。 |
| 博士遴选 / 夏令营信息时间线 | Top | 招生触点必须清晰，不应做成普通招生海报。 |
| 社交媒体 Research Update 模板 | Optional | 形成持续传播节奏，适合科研动态和活动回顾。 |
| Sticker / pin / hoodie | Optional | 等主系统稳定后，用于学生社区和活动身份。 |
| 校园导视 / 门头 | Not first | 不是第一轮重点；等标志、网格和字体规则稳定后再做空间化。 |

## 11. 设计禁区

必须避免：
- 校徽盾牌、麦穗、书本、火炬、金色边框。
- 通用 AI 符号：大脑、芯片、蓝紫渐变人脸、机器人吉祥物。
- 过度政府展板感：红蓝大标题、宏大口号堆叠、会议背景板式构图。
- 过度赛博朋克：霓虹、黑客雨、城市科幻、故障字。
- 只做“招生视觉”：创智学院的品牌核心不是录取，而是前沿研究和项目共同体。

## 12. Prompt-ready art direction language

以下语言可直接给后续图像生成或设计探索使用，但需要设计师二次筛选，不应机械套用。

### A. Primary logo exploration
> Minimal institutional logo for “Shanghai Innovation Institute / SII”, generated from a precise 8x8 computational grid, abstract SII letterforms revealed through illuminated nodes and short connecting line segments, compact geometric mark, intelligent research institute identity, deep compute navy background, signal cyan accent only, bilingual Chinese-English lockup space, no shield, no brain, no chip, no gradients, no mascot, vector, high legibility at favicon size.

### B. Website hero system
> Design a digital hero visual for an AI research and innovation institute in Shanghai, dark laboratory atmosphere, modular signal grid, topology nodes, scanning line, transparent data panels, bilingual typography, high-density but orderly information architecture, Deep Compute Navy #07111F, Signal Cyan #00D1FF, Surface Fog #F4F7FA, restrained scientific credibility, frontier signal station, not a university brochure, not generic AI brain, no neon cyberpunk.

### C. Research project card
> High-density research project showcase card for Shanghai Innovation Institute, structured like a scientific operating system dashboard, project title, metadata, status badge, evidence block, abstract tensor slices and node topology, clean bilingual grid typography, dark and light variants, signal cyan used only for data highlights, precise alignment, credible academic-tech tone, no decorative stock imagery.

### D. TechFest / open day key visual
> Event key visual for an AI maker-scientist community, “TechFest / Future Intelligence” tone, dynamic signal beacon emerging from a computational grid, project demo energy, disciplined typography, one strong cyan signal line, subtle violet secondary accent, poster layout with date and venue modules, futuristic but credible, not startup hype, not school admissions poster.

### E. Admissions selection timeline
> Doctoral selection information timeline for a new AI institute, clear stages, dates, assessment modules, code-like labels, modular grid, high readability, institutional trust, signal path connecting milestones, no smiling student stock photos, no generic campus brochure style.

## 13. 最终建议

第一轮不要做“完整校园 VI 包”，而要先做一套能立即投入传播的**数字优先品牌系统**：
1. SII Grid Mark + 中英文组合；
2. Frontier Signal Grid 辅助图形规则；
3. 官网 hero 与研究卡片；
4. TechFest / 开放日 KV；
5. 博士遴选时间线模板；
6. 社交 Research Update 模板。

这样才能回应真正的任务：不是总结创智学院是什么，而是让公众、候选人和合作方一眼看见——**创智学院是中国 AI 前沿人才与项目的运行现场。**
