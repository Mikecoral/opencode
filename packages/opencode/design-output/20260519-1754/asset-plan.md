# Asset Generation Plan

## Rationale
上海创智学院的 brief repeatedly frames the organization as an AI research-and-maker community rather than a conventional academic institution: “AI 科学家创客社区 + 顶尖人才培养平台 + 产业创新加速器.” Section 11 places research/project communication, admissions-selection information, event key visuals, and web/social content as Top priority, so this run should build a coherent research-signal digital identity system rather than a campus/admissions sampler.

## Visual Direction
- Selected: research-signal
- Why: Section 5 explicitly names “AI Infra / 算力 / 网格,” “前沿信号 / 动态雷达,” and “破界与跨学科”; Section 7 keywords include “前沿信号、算力网格、动态拓扑、科学可信.”
- What this prevents: Avoids a traditional university crest/campus bundle and avoids generic blue “AI school” marketing graphics. The system should feel like evidence-rich research communication, not a brochure set.

## Deliverable Strategy
- Selected: digital-system
- Why: Section 11 ranks “官网与社交内容系统,” “科研成果 / 项目展示模板,” “招生营 / 博士遴选信息系统,” and “Event key visual” as Top priority. These are all recurring digital/content surfaces that need one shared visual language: grid, signal, typography, and high-density information hierarchy.

## Self-Check
- Does this plan avoid the predictable industry bundle? Yes — it avoids campus beauty shots, generic admissions posters, brochures, and merchandise, focusing instead on research-signal communication for a new AI institution.
- Are all non-logo assets tied to Top priority touchpoints or the selected strategy? Yes — every included asset supports research/project display, admissions information, event key visuals, or website/social content, all ranked Top priority in Section 11.
- Did you avoid defaulting to color-palette/campus/admissions/brochure/merchandise? Yes — color-palette, campus, brochure, and merchandise assets are rejected; admissions appears only because Section 11 marks it Top priority and it is framed as an information-system module.
- Does the set feel like one coherent system rather than unrelated samples? Yes — all assets share a research-signal direction, digital-system strategy, SII grid generation, data-rich typography, Deep Compute Navy, and Signal Cyan accent discipline.
