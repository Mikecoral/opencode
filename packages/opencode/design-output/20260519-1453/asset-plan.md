# Asset Generation Plan

## Rationale
创智学院的关键差异不是“学院”身份本身，而是“面向 AI 无人区的研究型学院 + 科学家创客社区 + 产业转化平台”。首轮资产应把“前沿信号体系、参数化网格、算力中台、项目制共创”转译为可复用的科研发布与官网/社媒视觉系统，而不是先做传统高校招生册、校园图或院章。

## Visual Direction
- Selected: `research-signal`
- Why: Brief Section 4 明确要求视觉语言“可像雷达、信号流、动态坐标，而不是静态盾牌”；Section 5 将“前沿信号体系”定义为扫描线、雷达圆弧、动态坐标、方向簇、信号峰值，并把 AI 基础设施表达为网格、节点、数据流、终端窗口。
- What this prevents: 避免落入普通高校的 `institutional-minimal` 院徽/校色/校园照片套路，也避免把全年招生营和 TechFest 做成互不相关的活动海报 sampler。

## Deliverable Strategy
- Selected: `digital-system`
- Why: Section 11 中“科研成果发布模板”和“官网与社媒的动态视觉语言”均为 Top priority，且官网是招生、科研、招聘、产业合作的统一入口。数字系统可以承载科研成果、训练营、TechFest 三类高频传播，同时保持同一套参数化信号语言。

## Self-Check
- Does this plan avoid the predictable industry bundle? yes — 没有采用“学校 = 校徽 + 校园 + 招生册 + 周边”的默认包，而是围绕研究信号与数字传播系统组织资产。
- Are all non-logo assets tied to Top priority touchpoints or the selected strategy? yes — research、website/social、training camp、TechFest 均来自 Section 11 Top priority；glyph system 是支撑 digital-system 的核心图形语言。
- Did you avoid defaulting to color-palette/campus/admissions/brochure/merchandise? yes — color-palette 只在 tokens 中记录，不生成；campus/wayfinding 为 Optional 被延后；merchandise 为 Not this round 被拒绝；招生只保留一个数字卡片而非 admissions bundle 或 brochure。
- Does the set feel like one coherent system rather than unrelated samples? yes — 所有资产共享 SII 参数化网格、雷达/扫描线、动态坐标、节点数据流、深色基础设施底色与单一高能信号青色。
