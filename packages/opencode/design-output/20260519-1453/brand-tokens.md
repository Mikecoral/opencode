# Brand Tokens: 创智学院（上海创智学院 / Shanghai Innovation Institute）

## Color Palette
| Role | Name | Hex | Usage |
|------|------|-----|-------|
| Primary | Infrastructure Black | #080A0F | Logo fields, dark UI surfaces, research infrastructure backgrounds, terminal-like layouts |
| Accent | Signal Cyan | #00E5FF | CTAs, radar sweeps, data-flow highlights, active states, signal peaks |
| Surface | Proof White | #F7FAFC | Publication backgrounds, readable cards, reports, high-contrast text areas |
| Muted | Mist Gray | #D6DEE8 | Dividers, secondary labels, chart scaffolds, quiet grid lines |

**Accent discipline:** one accent color only. Critic will flag a second accent as anti-slop violation.

## Typography
| Role | Style Description | Weight Range |
|------|-------------------|-------------|
| Display / Logo | Narrow, high-readability modern sans with engineering precision; compressed spacing for command-line / research-release intensity | Semibold / Bold / Black |
| Body | Neo-grotesque / humanist sans; clear, academic, highly readable in bilingual digital content | Regular / Medium |
| Caption | Compatible sans with optional monospaced treatment for code, parameters, data IDs, project labels | Light / Regular |
