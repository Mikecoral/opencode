## Design Direction

The final identity uses an “Intelligent Grid” concept: a modular 创/智 master mark, Chinese-first typography, a research-operating-system visual grammar, and a disciplined palette of deep navy, cloud gray, innovation blue, cyan nodes, and limited orange for recruitment CTA only.

## Production Notes

- Keep one master 创/智 mark. Do not introduce checker logos, S monograms, seals, brain/chip/chatbot icons, rockets, graduation caps, or generic circuit wallpaper.
- Use orange only for recruitment calls to action such as `申请加入`.
- For certificate issuance, connect the QR verification block to an official verification page before real use.
- For accessibility, test small-size logo contrast and English gray text contrast in final vector production.
