# Design Assets Iteration 2: Production Refinements

Active base system: `packages/opencode/design-output/20260520-0223/iter-1/`

This iteration adds production-hardening refinements from audience testing. It does not replace the complete `iter-1` system; it supplements it with improved variants for launch use.

## Refinement Goals

- Improve small-size recognition of the modular 创/智 master mark.
- Reduce route/node density on recruitment and forum graphics.
- Add formal credential verification details.
- Add a dashboard legend explaining node/path semantics.
- Provide an international-facing lockup with a larger English line.

## Assets

1. `sii-intelligent-grid-mark-small.png` — Small-size optical master mark variant with 48px / 32px / 24px previews.
2. `sii-open-day-recruitment-banner-low-density.png` — Lower-density open-day banner with more negative space and one dominant active route.
3. `sii-frontier-forum-event-poster-low-density.png` — Lower-density forum poster with modern technical sans hierarchy.
4. `sii-certificate-credential-verified.png` — Certificate variant with QR-style verification, authorized-signature placeholder, and consistent mark-derived seal.
5. `sii-research-operating-dashboard-legend.png` — Dashboard variant with compact node/path legend.
6. `sii-international-master-lockup.png` — International-facing lockup variant with larger English name.
