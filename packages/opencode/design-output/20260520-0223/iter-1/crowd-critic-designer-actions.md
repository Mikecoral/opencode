# Crowd Critic Designer Actions

## Priority 1: Small-Size Master Mark Variant

Create an optical small-size version of the master 创/智 mark for favicon, dashboard header, certificate seal, wayfinding corner, and social avatar use.

Requirements:

- Preserve the same 创/智 modular identity logic.
- Reduce tiny internal interruptions and hairline route details.
- Keep navy/blue/cyan palette, but ensure it works as one-color navy and one-color white.
- Do not create a new symbol, checker logo, S monogram, or alternate grid mark.

## Priority 2: Lower-Density Campaign Variant

Create lighter variants for the open-day banner and forum poster.

Requirements:

- Use one dominant #0F62FE route per layout.
- Use sparse #00A3FF node highlights.
- Preserve more negative space for accessibility and institutional calm.
- Keep orange only for `申请加入` in recruitment contexts.
- Avoid generic glowing tech wallpaper.

## Priority 3: Verification/Trust Detail Kit

Add optional trust details for formal and institutional assets.

Requirements:

- Certificate: add optional QR verification area, signature placeholder, and digital credential note.
- Dashboard: add a compact legend explaining route/node meaning without adding generic metrics.
- International-facing lockup: create a variant where `Shanghai Innovation Institute` is slightly larger for overseas partner documents.

## Recommendation

These actions are refinements, not blockers. The current `iter-1` system can be delivered as the main concept package; the above should be considered production-hardening before real launch.
