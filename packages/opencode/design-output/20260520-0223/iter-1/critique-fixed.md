## Craft Notes
### Color
The color system is brief-aligned: white/cloud gray and deep navy dominate, innovation blue acts as the main route/action color, cyan appears as a secondary node signal, and orange is correctly reserved for recruitment CTA moments. Accent density is still high in the open-day banner and forum route diagrams, but it reads as system grammar rather than generic glow/gradient slop. Minor caution: if scaled into a full campaign, reduce repeated blue/cyan node counts so the brand remains institutional rather than decorative-tech.

### Typography
Chinese-first hierarchy is strong across the landing page, open-day banner, certificate, wayfinding sign, and dashboard. The corrected forum poster now supports institutional credibility by using the official English name. The main typographic caveat remains the formal serif treatment on the forum poster and annual report: it is elegant and credible, but slightly outside the brief’s modern technical sans center of gravity.

### Hierarchy
The dashboard now has a clear top bar, consistent master mark, and readable route rows for learning path / research base / outcome transfer. The landing page and recruitment banner have strong CTA hierarchy. The forum poster is legible and appropriately academic, though its left-side value-icon stack competes slightly with the system’s modular-grid language.

## Top 3 Iteration Recommendations

### 1. Preserve the Master Mark at Small Sizes
**Issue:** The mark is distinctive but still visually dense when used small.
**Fix:** Create a simplified small-size optical cut with fewer internal interruptions while preserving the 创 / 智 logic.
**Ready-to-use imagegen prompt:**
Create a small-size optical version of the 创智学院 modular master mark for favicon, dashboard header, certificate seal, and wayfinding use. Preserve the same 创 / 智 grid logic and navy/blue/cyan palette, but simplify tiny gaps and internal strokes for clear recognition at 24–48px. No alternate symbol, no pixel/checker redesign.

### 2. Reduce Decorative Node Density on Campaign Graphics
**Issue:** Route and node accents are strategically correct, but open-day and forum graphics risk becoming decorative wiring when repeated heavily.
**Fix:** Use one dominant active route per layout, fewer cyan nodes, and more quiet negative space.
**Ready-to-use imagegen prompt:**
Refine the open-day banner and forum poster using one primary #0F62FE active route, sparse #00A3FF node highlights, and generous navy/white negative space. Keep the official “Shanghai Innovation Institute” lockup and the single modular 创 / 智 mark. No generic tech wallpaper, no glow-heavy network background, no extra icons.

### 3. Align Formal Typography With the Technical System
**Issue:** The serif headline style on the forum and annual report is credible but slightly separate from the technical sans/grid identity.
**Fix:** Test a stronger modern sans or hybrid type treatment for formal materials.
**Ready-to-use imagegen prompt:**
Regenerate the annual report cover and forum poster with a more modern institutional sans-serif headline system: Chinese-first, high-weight, tightly set, grid-aligned, with IBM Plex Sans or similar Latin support. Preserve deep navy, cloud gray, innovation blue, the official “Shanghai Innovation Institute” name, and the modular 创 / 智 master mark.
