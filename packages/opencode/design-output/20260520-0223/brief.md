# Brand Design Brief: 创智学院 / Shanghai Innovation Institute

## 1. Organization Overview

创智学院（官方英文名：Shanghai Innovation Institute；官方语境中也称“上海创智学院”）不是普通培训机构或在线课程平台，而是以上海为基地、面向人工智能前沿的新型人才培养机构。研究资料显示，学院由顶尖大学、头部企业与科研机构共同参与建设，位于上海徐汇西岸 / 北杨人工智能小镇，承担“培养中国 AI 领军人才、打造世界人工智能创新高地”的高规格使命。

学院的核心特征包括：

- **前沿 AI 人才培养**：面向博士阶段及高潜青年科研人才，强调大模型、具身智能、科学智能、AI 基础设施、AI 安全等方向。
- **阵地式 / 项目制培养**：围绕真实研究问题、产业场景和导师组资源组织学习，而非传统固定课程体系。
- **高校—企业—科研—资本生态**：连接 31 所高校、头部企业、独角兽企业、科研机构、投资与孵化资源。
- **稀缺资源支撑**：高性能算力、数据平台、导师网络、创业孵化、产业场景与实践项目。
- **年轻、高能、实验性**：虽然具有国家战略与城市创新平台属性，但媒体与官方资料均强调学生中心、自主选择、敢闯无人区、Researcher Founder 等新型培养气质。

**设计前提假设**：本 brief 将其定位为“AI 时代的前沿研究型人才培养与创新转化平台”，而非传统高校院系、成人职业培训品牌或泛知识付费平台。

## 2. Brand Positioning

### 核心定位

**创智学院是连接前沿 AI 研究、青年领军人才、产业转化与城市创新战略的新型智能人才操作系统。**

品牌需要同时承担四种角色：

1. **研究前沿入口**：让顶尖学生相信这里能接触真正有挑战的问题、算力、导师与产业场景。
2. **国家级 / 城市级可信平台**：让政府、高校、企业和社会公众感知其正规性、长期性和公共价值。
3. **青年创造者共同体**：让学生觉得这里不只是“被培养”，而是可以主导研究、创业和真实影响。
4. **AI 转化加速器**：让企业与产业伙伴看到从算法、系统到场景落地的能力。

### 竞争与差异

竞品 / 参照品牌中，Coursera、IBM SkillsBuild 代表蓝色系、可信赖、产品系统化的在线学习与职业技能平台；得到、极客邦代表中国知识服务与技术学习市场中常见的橙色商业化视觉；混沌学园偏创新商业与认知学习；Duolingo、Brilliant 代表更亲和、游戏化或互动式学习体验。

创智学院应避免：

- 成为泛蓝色“科技教育 logo”；
- 成为橙色知识付费 / 课程销售平台；
- 成为传统红金高校 / 书院风；
- 成为低龄化、卡通化 AI 科普品牌。

它的差异应来自：**前沿智能 + 结构化系统 + 上海创新生态 + 青年研究者的高能创造力**。

## 3. Target Audience

### Primary Audience — 博士级 AI 前沿人才 / 未来 AI 领军者

- **年龄与阶段**：主要为研究生、博士生及具备博士培养潜力的高水平青年人才，约 22–32 岁。
- **动机**：接触前沿课题、获得导师组与算力资源、拥有自主选择方向的空间、把科研转化为论文、开源、专利、产品或创业。
- **心理特征**：高智识、高自驱、风险承受力强，渴望进入“无人区”，不满足于传统课程与单一导师制。
- **视觉需求**：需要看到严肃、先进、系统化的研究平台，同时感到这里允许年轻人突破规则、建立新东西。

### Secondary Audience — 高潜本科 / 硕士 / 预备营学员

- **年龄与阶段**：约 18–28 岁，具有计算机、AI、电子信息、数学、工程等基础。
- **动机**：获得 AI 前沿认知、实践项目、证书 / 认可、进一步申请或加入创智体系的机会。
- **视觉需求**：既要有精英门槛，又不能过度冷峻；应传达“可进入、可成长、可被点燃”。

### Tertiary Audience — 产业工程师 / FDE 转型人群

- **年龄与阶段**：约 25–50 岁，包含工程师、技术负责人、行业部门负责人。
- **动机**：掌握 AI 落地方法、解决真实产业场景、职业转型、组织升级。
- **视觉需求**：更强调工具性、可实施性、专业可信、场景导向。

### Institutional Audience — 政府、高校、企业、科研与投资伙伴

- **诉求**：人才管线、科研转化、产业场景、社会与经济价值、治理可信度。
- **视觉需求**：必须显得稳健、清晰、有秩序、有公共机构级别的可靠性。

## 4. Brand Personality & Values

### Personality

- **前沿的**：站在 AI 科学与产业变革前线。
- **系统的**：不是零散课程，而是有架构、有资源、有路径的创新体系。
- **理性的**：重视科学、工程、数据、验证和真实成果。
- **开放的**：跨高校、跨企业、跨学科、跨场景协作。
- **高能的**：由年轻研究者、工程师和创业者推动，具备速度感与实验性。
- **可信的**：具备公共机构、顶尖高校与产业生态背书。

### Core Values

1. **以学生为中心**：赋予青年人才选择权、探索权和创造权。
2. **以前沿为牵引**：围绕真正未解决的问题组织培养。
3. **以系统为支撑**：导师、算力、数据、场景、资本形成完整生态。
4. **以实践为检验**：论文之外重视经济价值、社会价值和产业落地。
5. **以开放促创新**：高校、企业、研究机构、创业团队共同构成智能网络。

### Tone of Voice

中文语气应：坚定、简洁、未来感、研究型、有行动号召；避免空泛励志与商业培训腔。

示例语感：

- “进入 AI 前沿问题现场”
- “让青年研究者成为智能时代的开拓者”
- “从算法到系统，从场景到价值”
- “为无法被标准答案定义的问题而来”

## 6. Visual Direction

### Selected Direction: 智能格局 / Intelligent Grid

建议以 Direction 1“智能格局”作为主品牌方向，并吸收 Direction 2 的现代学院可信感、Direction 3 的青年动能作为辅助层。

### Core Idea

建立一个可扩展的“智能格局”视觉系统：以网格、模块、节点、路径和生成式结构表达创智学院如何把学生、导师、算力、数据、研究阵地、产业场景与创业资源组织成一个前沿 AI 人才培养系统。

它应像一个 **research operating system**：严谨、可计算、可扩展，但不冰冷；具备公共机构的秩序感，同时允许年轻创造者在系统中产生突破。

### Aesthetic References

- **MIT Media Lab**：用基础网格生成主标识与不同研究组符号，适合作为创智学院多方向、多课程、多阵地系统的参考。
- **IBM Design Language**：蓝色、黑白灰、网格、数据可视化与设计系统带来的技术可信度。
- **The New School**：现代学院气质与强类型系统，避免传统大学保守感。
- **Dropbox modular identity**：用基础形体组合出协作、碰撞、聚合的意象，可用于表现跨学科与生态协同。

### Mood

- 基调：冷静、前沿、结构化、可信。
- 动势：节点正在连接、路径正在生成、研究方向正在展开。
- 温度：通过局部高亮色、人物 / 项目摄影、开放留白与动态生成图形体现青年能量。

## 7. Color Strategy

### Palette Direction

建议采用“深色技术底盘 + 高亮智能蓝 + 少量青绿 / 暖色动能”的组合。

#### Primary

- **Deep Intelligence Navy / 近黑深蓝**：`#07111F` 或 `#0B1020`  
  用于主背景、正式传播、发布会主视觉，建立前沿科技与权威感。

- **Innovation Blue / 智能蓝**：`#0F62FE` 或 `#0056D2`  
  借鉴 IBM / Coursera 类别中的信任与技术感，作为主识别色、行动色和关键节点高亮。

#### Secondary

- **Data Cyan / 数据青**：`#00A3FF` 或 `#00C2D1`  
  用于连接线、动态图形、图表、科技氛围，不应大面积泛用。

- **AI Green / 生长青绿**：`#18B99A`  
  表达成长、系统自适应、开放生态，可用于项目进展、课程完成、创新孵化等场景。

#### Neutral

- **White / 清晰白**：`#FFFFFF`
- **Cloud Gray / 信息浅灰**：`#F4F7FA`
- **System Gray / 系统灰**：`#DDE3EA`, `#8A96A8`
- **Charcoal / 正文深灰**：`#161616`

#### Accent for Recruitment / Events

- **Spark Orange / 创造橙**：`#FF7A1A`  
  仅用于青年招募、营地、开放日、活动倒计时、call-to-action，不作为主品牌色，避免落入知识付费平台视觉。

### Color Psychology

- 蓝色解决“可信、技术、国际化、研究级”的核心要求。
- 深蓝 / 黑色让品牌区别于轻量教育 App，进入研究机构与基础设施语境。
- 青色与绿色提供 AI 系统的活性与未来感。
- 少量橙色保留青年动能和行动号召，但必须被网格系统约束。

## 8. Typography Direction

### Chinese Typography

建议使用现代、清晰、技术感强的中文黑体系统：

- 正式品牌 / 标题：思源黑体 / Noto Sans CJK SC / HarmonyOS Sans SC / 阿里巴巴普惠体等现代无衬线，可选择较高字重增强机构感。
- 长文与信息界面：优先保证中文可读性、数字清晰度和多屏幕适配。
- 标识字形可定制：围绕“创”“智”两字进行局部结构化处理，如开放的“门 / 刀”结构、网格化“日 / 知”结构，但避免书法化或篆刻化。

### Latin Typography

建议搭配 IBM Plex Sans、Inter、Source Sans 3 或类似的人文 / 工程感无衬线字体。

### Type Personality

- **不建议**：圆体、手写体、卡通感字体、传统宋体书院风作为主系统。
- **建议**：几何秩序 + 人文可读性。标题可以偏紧凑、硬朗；正文和 UI 保持开放、清晰。
- **可探索**：变量字重 / 字宽系统，用不同宽度表达“研究方向展开、学科交叉、路径生成”。

## 9. Symbol & Mark Strategy

### Master Mark Concept

标识应从“创智”二字和“智能格局”概念出发，构建一个可扩展的模块化符号系统，而非单一装饰性图案。

建议探索方向：

1. **“创 / 智”结构抽象**  
   从“创”的开辟、切入、打开结构，与“智”的知识、判断、日光 / 认知结构中提炼几何模块。

2. **7×7 或 8×8 智能网格**  
   以固定网格生成主标识、研究方向图标、课程标签和活动图形，形成长期可运营的品牌资产。

3. **节点—路径—阵地系统**  
   节点代表学生、导师、算力、数据、企业场景；路径代表培养轨迹；阵地代表认知智能、情境智能、具身智能、科学智能、AI 基础设施等方向。

4. **中英文兼容锁定**  
   中文“创智学院”应为主识别；英文 “Shanghai Innovation Institute” 作为正式国际化副标。需设计横版、竖版、纯中文、纯英文、图形单独使用版本。

### Symbol Requirements

- 必须在小尺寸 favicon、社交头像、证书章、PPT 角标、胸牌和空间导视中清晰可辨。
- 应具备严谨几何逻辑，但不能像普通芯片、电路、AI 大脑或聊天气泡图标。
- 应支持生成子品牌：招生营、前沿课程、FDE 项目、AI 安全短课、开放日、研究阵地、创业孵化等。

### What to Avoid

- 抽象电路线、发光大脑、机器人头、毕业帽、书本、火箭等通用 AI / 教育符号。
- 红金印章、毛笔字、传统书院门楼等文化符号堆砌。
- 过度拟物化、卡通化、低龄化 mascot。

## 10. Application Contexts

### Digital

- 官网首页与招生专题页
- 课程 / 训练营报名页面
- 研究阵地介绍页
- 导师与项目数据库界面
- 证书、邮件模板、公众号头图、视频封面
- 数据看板、学习路径、项目进展可视化

### Print & Institutional Materials

- 招生简章、项目手册、年度报告
- 证书、录取通知、课程结业文件
- 合作伙伴提案、政府 / 企业汇报 PPT
- 学术海报、论坛议程、研究成果发布物

### Environmental & Event

- 徐汇西岸 / 北杨人工智能小镇校区导视
- 前台背景墙、会议室 / 实验室命名系统
- 训练营、开放日、AI 安全短课、FDE 班级活动物料
- 胸牌、工牌、服装、旗帜、展板、签到系统

### Motion & Generative System

- 可用网格节点生成动态开场：从散点到结构、从路径到阵地、从问题到成果。
- 研究方向可通过不同模块组合形成动态图标。
- 招生传播可使用“路径被点亮”的动效，表达学生进入系统、连接资源、产生突破。

### Photography / Imagery Guidance

- 推荐真实空间、真实学生、导师讨论、实验设备、机器人 / 具身智能、代码与数据可视化、路演与创业场景。
- 风格应克制、清晰、有现场感；避免库存照片式握手、假笑课堂、泛科技蓝光背景。

### System Principle for Designers

所有视觉资产应遵循一个核心判断：**它是否让创智学院看起来像一个能组织前沿 AI 人才、问题、资源和成果的高能系统？** 如果只是“科技感”或“教育感”，则不够创智。
