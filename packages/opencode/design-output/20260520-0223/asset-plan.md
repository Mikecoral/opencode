# Asset Plan: 创智学院 / Shanghai Innovation Institute
Design goal: Build a rigorous but high-energy “Intelligent Grid” identity system that positions the institute as a research operating system for frontier AI talent, credible to government/university/industry partners while compelling to young doctoral-level researchers.

| # | Filename | Type | Size | Justification |
|---|----------|------|------|--------------|
| 1 | sii-intelligent-grid-mark | identity mark / symbol | 1024×1024 | The brief explicitly calls for a scalable core mark derived from “创 / 智,” a 7×7 or 8×8 grid, nodes, paths, and research positions; this asset establishes the small-size symbol for favicon, avatar, certificate seal, badges, PPT corners, and signage. |
| 2 | sii-bilingual-master-lockup | wordmark / lockup | 1536×1024 | The institute needs Chinese-first recognition with the official English name as an international secondary line; a bilingual lockup is essential for formal public, university, government, and enterprise-facing materials. |
| 3 | sii-intelligent-grid-system-board | visual-system board | 1536×1024 | The main design idea is a generative “research operating system”; this board should define the disciplined grid, modular shapes, palette hierarchy, type hierarchy, and node/path graphic language so the identity can scale beyond a single logo. |
| 4 | sii-research-directions-module-set | other brief-specific asset | 1536×1024 | The brief requires subbrand support for research fronts such as large models, embodied intelligence, scientific intelligence, AI infrastructure, and AI safety; a module set demonstrates how the master grid creates direction icons or labels without generic AI clichés. |
| 5 | sii-admissions-landing-surface | digital surface | 1536×1024 | Recruitment pages and training-camp registration are primary digital touchpoints; this asset should show how the brand converts high-potential students through a serious, frontier-facing admissions interface rather than a consumer course platform. |

| 8 | sii-frontier-forum-event-poster | campaign poster / event banner | 1536×1024 | Forums, academic posters, agendas, and research-result releases are named institutional touchpoints; a poster tests the identity in a public-facing event context where scholarly credibility and high-energy frontier AI must coexist. |
