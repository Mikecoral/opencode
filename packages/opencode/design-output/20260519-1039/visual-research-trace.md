# Visual Research Trace

## Queries
- Query: “AI research lab brand identity modular grid education technology”
  - Results considered: MIT Media Lab by Pentagram; generic agency case studies; university crest systems.
  - Why selected / rejected: Selected MIT Media Lab because it directly demonstrates a research-lab identity generated from one grid across many groups. Rejected crest/university references because the brief explicitly avoids traditional school-emblem cues.
- Query: “white gray technology design system grid color tokens data visualization”
  - Results considered: IBM Carbon color and 2x grid; Material Design 3 color page; generic SaaS design systems.
  - Why selected / rejected: Selected Carbon because it gives concrete white/gray layering, role-based color, and 8px grid logic for dense interfaces. Material Design 3 page required JavaScript in fetch and was not used as a core reference.
- Query: “AI brand guidelines white space typography research papers”
  - Results considered: OpenAI Design Guidelines; Google DeepMind site; other AI company landing pages.
  - Why selected / rejected: Selected OpenAI for light-background restraint, clear-space discipline, AI research collateral, and humanistic sans cues. Selected DeepMind for bright research/model architecture and card-based research communication. Rejected darker AI company sites that rely on black, neon, or speculative 3D visuals.
- Query: “research organization website publication cards code tools visual system”
  - Results considered: IBM Research; IBM Design Language; general academic lab websites.
  - Why selected / rejected: Selected IBM Research for news/tool/research card logic and IBM Design Language for full-system scope across typography, diagrams, photography, and data. Rejected ordinary academic lab sites because they were too template-like and visually under-systematized.

## Webfetches
- URL: https://www.pentagram.com/work/mit-media-lab/story
  - Extracted visual lessons: One geometric rule can generate both a master mark and many research-group glyphs; Helvetica-like neutrality supports complexity; identity and wayfinding should share the same modular logic.
- URL: https://carbondesignsystem.com/elements/color/overview/
  - Extracted visual lessons: White/Gray 10 light themes create depth by alternating layers; neutral gray should dominate; one primary action color plus sparse support colors keeps dense interfaces calm; role-based tokens prevent palette sprawl.
- URL: https://carbondesignsystem.com/elements/2x-grid/overview/
  - Extracted visual lessons: 8px mini-units, 2x division/multiplication, fixed padding, key lines, and aspect-ratio constraints can make research cards, dashboards, and posters feel like one system.
- URL: https://www.ibm.com/design/language/
  - Extracted visual lessons: A technical organization needs rules for type, color, grid, iconography, illustration, photography, data visualization, infographics, layout, and animation; SII should not stop at logo/color/type.
- URL: https://openai.com/brand/
  - Extracted visual lessons: White fields, black typography, strict clear space, minimal marks, soft pastel research covers, and a geometric-but-friendly sans can make AI feel precise without becoming cold or cyberpunk.
- URL: https://deepmind.google/about/
  - Extracted visual lessons: Bright card architecture can organize models, science, research, responsibility, careers, and news; project tiles and soft scientific imagery help multiple research streams feel coherent.
- URL: https://www.research.ibm.com/
  - Extracted visual lessons: Research communications need strong metadata hierarchy, tags, recent-news cards, tools/code modules, and technical/scientific imagery; this supports SII’s research release and open-source touchpoints.
- URL: https://m3.material.io/styles/color/overview
  - Extracted visual lessons: Fetch returned only a JavaScript-required notice, so it was rejected as a substantive source for this round.
- URL: https://www.brooklynmuseum.org/opencollection/archives
  - Extracted visual lessons: Fetch timed out and was rejected; not relevant enough to pursue further under the 3–5 reference target.

## Direction Differentiation Check
- How the options differ in color stance: Option 1 is cool white/silver with cyan-led signals; Option 2 is nearly monochrome glass/paper white with violet as a refined campaign spark; Option 3 is white/gray with proof green as the main evidence accent plus cyan/violet category support.
- How the options differ in typography: Option 1 balances neutral grotesk with small mono technical markers; Option 2 uses larger editorial bilingual typography and more spacious leading; Option 3 uses functional publishing hierarchy with a more visible monospaced evidence layer.
- How the options differ in layout: Option 1 uses modular grids, panels, key lines, and variable glyph logic; Option 2 uses asymmetrical editorial compositions, photography, and architectural whitespace; Option 3 uses maps, timelines, cards, tags, matrices, and proof trails.
- How the options differ in asset implications: Option 1 needs a variable grid/glyph engine and UI-like templates; Option 2 needs strong photography, glass/reflection art direction, and environmental graphics; Option 3 needs data visualization, collaboration maps, repo/release cards, and impact-report components.
