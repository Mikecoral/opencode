# Brand Tokens: 上海创智学院 / Shanghai Innovation Institute (SII)

## Color Palette
| Role | Name | Hex | Usage |
|------|------|-----|-------|
| Primary | Intelligence Ink | #1E2732 | Logo detail, headings, body text, high-contrast UI labels |
| Accent | Signal Cyan | #00C8F5 | Active signal paths, CTAs, data highlights, key grid nodes |
| Surface | White Field | #FFFFFF | Primary backgrounds, clean institutional space, core mark clear space |
| Muted | Cool Gray | #68727F | Secondary labels, metadata, inactive navigation, captions |
| Surface Layer | Mist Silver | #F5F7FA | Glass cards, page sections, template panels, light UI modules |
| Line | Infrastructure Silver | #D7DDE5 | Grid lines, separators, diagram strokes, glass-panel borders |

**Accent discipline:** one active accent color only for this generation run: Signal Cyan `#00C8F5`. Violet and green are acknowledged from the approved direction as possible future micro semantic states, but they are not active palette tokens for Phase 2 assets.

## Visual Research Inputs
Recommended direction: Option 1 `signal-glass-grid`, interpreted as the allowed Visual Direction `research-signal` for this run. Reference moves include MIT Media Lab’s underlying generative grid logic without copying its 7×7 ML form or rainbow personality; IBM Carbon’s white / gray layered interface discipline and 2x grid rhythm without IBM blue ownership cues; OpenAI’s white-space confidence and strict core-mark discipline without circular blossom imitation; DeepMind / IBM Research-style research card architecture without generic AI website warmth or dark hero dependency. Palette stance is white-first with mist silver, infrastructure silver, cool gray, and one active cyan signal accent. Type stance is modern bilingual grotesk with restrained monospaced metadata. Negative cues: no black/cyan cyberpunk hero, no full-rainbow grid, no traditional university crest, no red/blue/gold academic palette, no generic neural-network wallpaper, no stock-photo scientists.
