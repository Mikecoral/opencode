# Audience-Specific Subcopy: 上海创智学院

## Naming Rule

- 中文正式名称统一使用：**上海创智学院**。
- 英文名称统一使用：**Shanghai Innovation Institute**。
- 英文简称可使用：**SII**。
- 海报、活动页、物料页脚、主办方信息中不要单独写“创智学院”，除非作为历史活动标题或引用原文出现。

## Core Copy System

### Master Line

为改变世界的人，建立一所未来学院。

### English Master Line

Research. Build. Venture. For Good.

### Short Institutional Descriptor

上海创智学院是一所面向人工智能时代的新型研创型未来学院，连接顶尖人才、前沿科研与产业创新。
