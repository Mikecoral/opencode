# Crowd Critic Designer Actions

## Verdict

**Iterate, do not rethink.** The core identity direction is strong enough. Focus the next pass on clarity, audience access, and production readiness.

## Must Fix

1. **Poster action layer**
   - Add visible placeholders for date, venue, host / organizer, QR code or URL, and CTA.
   - Use a consistent event-info block across all posters.
   - Keep real small text minimal; use clearly readable labels only.

2. **Poster hierarchy and spacing**
   - Increase subtitle / slogan prominence by 10-20% on TechFest and Demo Day.
   - Add more breathing room in bottom modules, especially icon rows, maps, route panels, and radar areas.
   - Reduce decorative micro-lines where they compete with reading order.

3. **Audience-specific message variants**
   - Young talent: emphasize challenge, frontier research, mentor access, build culture.
   - Industry: emphasize projects, demos, partnership, technology transfer, application scenarios.
   - Government / education: emphasize mission, credibility, public value, responsible AI.
   - Public / parents / media: emphasize open visit, understandable experience, what visitors can see and do.
